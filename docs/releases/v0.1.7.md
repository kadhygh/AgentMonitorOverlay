# AMO v0.1.7

本版本相对 v0.1.6 新增独立的 DeepSeek Harness Lab，补充 DeepSeek V4 Pro Managed CLI 路由，并修复 Obsidian 已到前台但 Note 没有完成跳转的间歇性问题。

## 主要更新

### DeepSeek Harness Lab（实验功能）

- 在主界面 Open Settings 左侧新增 Harness Lab 入口，使用独立工具窗口，不与现有 Task Card、Codex 或 Claude 链路耦合。
- 未安装 Harness 时，可从面板把固定基线版本 `@deepseek-ai/dsh@0.1.0-rc.6` 安装到 AMO 的受管目录；Portable 优先使用包内 Node/npm，无需用户额外安装系统 Node 或 npm，但首次部署仍需联网访问 npm registry。
- 支持启动、停止由 AMO 拥有的 `dsh web` 后台进程，监测 PID、端口、网页健康状态和异常退出，并一键打开 `http://127.0.0.1:3080`。
- 使用独立 `DSH_HOME`、runtime 与日志目录；不修改全局 npm 包或用户现有 Harness 配置，不终止外部进程。
- 复用 Windows Credential Manager 中已有的 DeepSeek 与 GLM Key，只通过子进程环境传入；全新的受管配置会初始化 GLM-5.2 Anthropic-compatible Provider，密钥不写入 YAML、命令行或日志。
- Runtime 卡片显示基线、本地和远端版本；远端版本仅在用户主动检查时访问 registry，一键 Update 会重新确认并安装明确版本。Repair 修复当前版本，不会把已升级版本降回基线。
- 服务日志默认折叠，手动展开后显示只读诊断，并分别适配深色和浅色主题。
- 首次打开或窗口隐藏较久后重新拉起时显示轻量加载界面；隐藏期间暂停状态轮询，恢复时刷新 runtime、端口、服务和凭据状态。
- 修复新工具窗口遗漏 Tauri capability 后无法拖动、关闭的问题，并新增权限覆盖回归测试。

### DeepSeek V4 Pro Managed CLI 路由

- Codex 和 Claude Managed CLI 新增 DeepSeek V4 Pro，排序位于原有 V4 Flash 之上；V4 Flash 继续保留。
- Codex 使用官方 Responses-compatible 路由和 `deepseek-v4-pro` 模型名。
- Claude 使用官方 Anthropic-compatible 路由和 `deepseek-v4-pro[1m]` 模型名。
- V4 Pro 与 V4 Flash 复用现有 DeepSeek Credential Manager 条目；API Key 仅在对应 CLI 子进程环境中存在。
- 默认 Codex/Claude 选项仍尊重用户本地配置，第三方路由只作用于单次 Managed Launch。

### Obsidian Note 打开可靠性

- 当 Obsidian 已到前台但插件报告目标属于其他 vault 时，AMO 会使用新的协议请求 ID 重试正确 vault，避免旧终态 ACK 阻止第二次跳转。
- 仅 foreign-vault 拒绝会触发该重试；其他失败保持显式返回，避免重复打开或隐藏真实错误。

### 调查与后续路线

- 新增 DeepSeek Harness 分阶段开发路线：先独立运行与验证，再研究 Cordis Bridge、精确 Session 深链和未来 Card 集成。
- 保存 Zcode CLI、Hook 与任务跳转能力调查结果，作为后续评估资料；本版本不接入 Zcode。
- Harness Lab 当前仍是实验模块，尚未与 AMO Task Card 双向同步，也不承诺 DeepSeek Harness RC 版本之间的插件/API 稳定性。

## 更新提示

1. 退出旧版 AMO。
2. 解压 `AMO-v0.1.7-win-x64.zip`。
3. 如需保留历史状态，将旧版本的 `data/` 目录复制到新目录。
4. 启动 `AMO.exe`。
5. DeepSeek Harness 为按需实验功能：首次使用时打开 Harness Lab，点击 Install runtime，等待完成后再点击 Start service。
6. Harness 首次安装需要联网，依赖数量较多，可能需要数分钟；之后日常启停不会重复执行 npm install。

Portable 仍要求目标机器已安装使用相关功能所需的 Codex CLI、Claude CLI、Obsidian、Windows Terminal 与 WebView2。普通 AMO 运行和 Harness 首次部署均可使用 ZIP 内置的 Node/npm runtime。
