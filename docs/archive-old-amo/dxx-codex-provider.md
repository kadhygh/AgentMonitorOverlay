# DXX Codex CLI

AMO Models settings supports a separate DXX API key, stored in Windows Credential Manager. In **Workspace Center → 启动** or a task card's **本项目快速启动**, select **Codex CLI → GPT-Dxx**, then choose **GPT-5.6 Sol** (`gpt-5.6-sol`) or **GPT-6 Astra** (`gpt-6-astra`) under **启动模型**. Both entrypoints share the same launch form and API service. The default-model settings retain their individual preset choices. Both models share the same saved DXX key, provider `amo-dxx`, Responses API, and the exact base URL `https://gorilla-api.dxxapi.com` (no automatic `/v1` suffix).

Both models are included in the shared DXX catalog, so you can use **`/model`** inside a DXX CLI session to switch between them. Selecting the GPT-Dxx route defaults to GPT-6 Astra. A previously saved DXX/Sol default is migrated once to Astra; subsequent explicit defaults in **Settings → Models → Default Codex provider** are retained. The preset IDs remain `dxx` for Sol and `dxx-gpt-6-astra` for Astra, so recorded sessions keep their existing preset. Restart existing CLI processes to load the updated catalog.

The key is passed through `DXX_API_KEY` for that CLI process and removed from its terminal environment on exit. AMO does not write the key or provider into the shared Codex config/auth files. Managed resume uses the session’s recorded DXX preset and its saved key; save the key in Models settings to resume without re-entering it.

Managed resume reapplies the recorded launch preset. A model selected later through `/model` does not update AMO's recorded preset; after managed resume, use `/model` again if needed.

The model catalog uses Sol capability metadata from the OpenCodex upstream snapshot (b0900e556e50984a651a4c72db000e9285a6952a). Astra's default reasoning level, context limits (272,000 default / 872,000 maximum), reasoning choices, and speed tier metadata follow the local Codex 0.153.4 model cache fetched on 2026-09-08. Use Codex CLI 0.153.4 or later for the Astra catalog entry. Both entries keep AMO's existing coding instructions and DXX-compatible standard Responses transport and tool settings; they do not enable Responses Lite or require WebSockets/code mode.

The official [GPT-6 Astra model page](https://developers.openai.com/api/docs/models/gpt-6-astra) confirms the `gpt-6-astra` identifier. Codex's [configuration reference](https://learn.chatgpt.com/docs/config-file/config-reference) documents the `model_catalog_json` startup setting. Actual DXX gateway support and account access must be confirmed with a live request. These presets do not change Codex App or the existing GPT-Official preset, which still inherits local configuration.
