# AMO v0.1.6

本版本相对 v0.1.5 集中交付 DeepSeek Managed CLI 路由、运行时性能优化、更可靠的 Obsidian Note/Canvas 打开链路，以及 Task Card 到 VS Code 工程的快速跳转。

## 主要更新

### DeepSeek CLI 路由

- Codex Managed CLI 可选择 DeepSeek V4 Flash 路由，并使用官方 Responses API 兼容配置。
- Claude Managed CLI 可选择 DeepSeek V4 Flash 路由，统一映射 Claude 模型槽位。
- API Key 仅通过启动进程环境传递，不写入 workspace、session snapshot、PowerShell 命令或调试日志。
- 默认路由继续尊重用户现有的 Codex/Claude 本地配置。

### 会话与卡片性能

- Broker 快照改为异步、合并、原子写入，hook/event 热路径不再同步等待磁盘持久化。
- Overlay 改为 SSE-first 更新；只在断线、revision 缺口或集合变化时执行单次 reconciliation。
- Active sessions 默认使用轻量 summary；Archive 延迟分页加载，完整详情按需获取。
- 主界面每页最多显示 20 张卡，并保留翻页和页外注意提醒，避免后续卡片静默消失。
- 移除重复的 `Showing X-Y of Z` 提示；已有的 active lines 计数继续作为主摘要。
- 主界面新增手动刷新会话名称按钮，可重新读取 CLI 会话历史中的最新标题并立即更新卡片。

### VS Code 工程跳转

- Task Card 在 Canvas 后新增 `VS Code` 按钮，可直接打开或聚焦任务对应的工程。
- 已打开精确 workspace 时，AMO 使用 Win32 原生窗口激活，不再只依赖重复启动 `Code.exe`。
- 当任务目录与已打开目录是同一父目录下、具有相同 Git remote 的 sibling clone 时，可聚焦已经打开的仓库窗口；例如 `project_mining_dev2` 可跳转到 `project_mining`。
- 未找到匹配窗口时，AMO 会定位标准安装、Insiders、Scoop 或 PATH 中的 VS Code，启动任务目录并短暂重试聚焦；仍找不到可执行文件时回退到 `vscode://`。
- 打开 VS Code 不会清除 Review 状态；按钮带有忙碌态、底部反馈和调试日志。

### Obsidian 打开可靠性

- 移除同步 `tasklist` 进程扫描；改为带 650ms 硬超时和缓存的异步探针。
- vault 注册幂等，未变化时不再重写 Obsidian registry。
- Note/Canvas 打开使用唯一 `openRequestId`、插件 runtime heartbeat 和终态 ACK。
- 系统 URI 派发只表示“已派发”；只有插件完成查找、打开/复用、reveal 和 focus 后才确认成功。
- 超时重试复用同一个 request ID，防止重复打开标签页。
- Obsidian 插件升级到 1.5.0；既有 workspace 需要执行 Update/重新部署并在 Obsidian 中 reload，才能启用 confirmed-open 能力。

### Stable 与 Portable 运行

- Stable 启动在停止旧实例前完成 frontend/native 验证，并在失败时恢复原 executable。
- 新增 `amo:health` 和 `amo:restart`，分别用于只读就绪检查和无需重编译的 Stable 重启。
- 启动检查覆盖 Vite、当前源码 Broker、revision-bearing initial sessions 和原生 App。
- 进程发现不再依赖可能长时间阻塞的 WMI/CIM 全量枚举。
- Stable 重启改为直接启动 Vite 的 Node 入口，并在停止旧实例、释放端口和替换可执行文件时使用更可靠的进程生命周期检查。
- Portable cold smoke 使用带硬超时的 `netstat` 监听者识别，验证 Broker 确实由包内 Node 启动，并确认 App 退出后不会遗留 owned Broker。

## 性能验证摘要

- Hook/event handler：p95 2.93ms。
- Active session summary：p95 2.68ms。
- 缓存后的 Obsidian vault registration：p95 3.43ms。
- 原同步进程扫描实测中位数约 1.62s，现已从请求热路径移除。
- Broker unit tests：83/83 通过。
- Overlay runtime tests：13/13 通过。
- Overlay production build、Obsidian plugin build、Rust `cargo check`、Portable smoke 与 Stable readiness 均纳入发布验证。

## 更新提示

1. 退出旧版 AMO。
2. 解压 `AMO-v0.1.6-win-x64.zip`。
3. 如需保留历史状态，将旧版本的 `data/` 目录复制到新目录。
4. 启动 `AMO.exe`。
5. 在 Workspace Center 对已有项目执行 Update，并在 Obsidian 中 reload `md-anno-tools` 1.5.0。

Portable 仍要求目标机器已安装使用相关功能所需的 Codex CLI、Claude CLI、Obsidian、Windows Terminal 与 WebView2；Node runtime 已随 ZIP 捆绑。
