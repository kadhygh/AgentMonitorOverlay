# AMO 平台 改动说明

改动先写进「## 下一版」；发布时（`npm run release -- platform` 或 `auto`）它会改成 `## 版本号（日期）`，这一节就是平台上显示的改动说明。

## 下一版

## 0.9.26（2026-11-10）

- 平台崩溃时会留下转储文件（.dmp），方便查原因：更新通道是测试通道时开着，正式通道不开。文件在 `%LOCALAPPDATA%\AMO\platform-profile\Crashpad` 里，只存在这台电脑上，不上传，只留最近 5 个；平时不影响速度。平台装的其他工具也按这个通道决定。

## 0.9.25（2026-11-06）

- 每个工具卡片上、「设置 → 平台更新」里都多了「更新记录」，随时能点开：上面是当前装的版本和可以更新到的版本，下面按版本列出版本号、日期和改了什么，新的在上面。还没装的新版本标着「还没装」、用醒目的底色，一眼看出更新会带来什么；当前版本也标出来。以前改动说明只在有新版时显示在卡片上，更新完就看不到了。连不上服务器时，显示这台电脑上装过的版本带着的记录。之前发布的版本还没带完整记录，这时只列出这台电脑知道的几个版本（可以更新到的、装过的），之后发布的版本会带上以前所有版本的记录。原来卡片上「x.y.z 改了什么」照旧。
- 托盘图标拖到任务栏上之后，平台或工具更新到新版本时不再被折叠回去。Windows 是按程序所在的文件夹记「显示在任务栏」的，而每个版本装在自己的文件夹里，所以每次更新都会当成新程序、图标回到折叠区。现在平台会在启动后、以及看到工具开起来后，把你在上一版上的选择抄给新版本的图标（只在新版本你还没动过时；你上次是折叠的就保持折叠）。

## 0.9.24（2026-11-05）

- 重启 Studio 时，后台已经停了、旧的 Studio 窗口进程 10 秒还没退出，平台会把它结束，再打开已装的新版（会话都在后台里，不受影响），结果里会写明这一点。以前它一直等到 60 秒，然后报「旧的 Studio 还没退出」，新版没打开。
- 重启 Studio 的过程中，卡片显示「正在重启」，「打开」「关闭」变灰，点不了。

## 0.9.23（2026-11-05）

- 下载进度和安装包大小统一成一位小数（如「8.0 KB」「1.5 GB」），和 AMO 的其他工具一样。以前 10 KB 以下带小数、以上取整，GB 带两位小数。

## 0.9.22（2026-11-04）

- 工具卡片上的「关闭」快多了：点下去马上显示「◐ 正在关闭…」，工具一退出卡片就跟着变，不再固定等 4 秒再查。打开时也一样，工具一起来就显示「正在运行」。以前每次都要把电脑上所有进程查一遍（这台机器约 1.8 秒），现在先看工具自己记下的进程号和平台自己启动过的进程，都不知道时才去查所有进程。需要各工具更新到这一版之后的版本才最快；旧版本照旧能用，只是慢一些。
- 重启 Studio 后，卡片每半秒看一次新后台起来了没有，起来就更新，不再固定等 5 秒。
- 关闭、重启 Studio、重启平台每一步用了多久，记在 `%APPDATA%\AMO\platform.log` 里，慢的时候可以看是卡在哪一步。
- 工具卡片的「⋯」菜单滚动鼠标滚轮、切到别的窗口时也会关上；菜单开着时按 Esc 只关菜单。

## 0.9.21（2026-11-03）

- 「设置 → 平台更新」多了「用完整包更新」：「更新平台」卡住时点它，一次下载整个平台的压缩包，用的是另一条下载路（不是平时逐个文件下载的那段代码），断了再点会接着下；下完自己解压、逐个文件按清单核对，再点「重启平台」换过去。要团队服务器的中转服务 0.7.10 以上，旧的会提示先更新中转服务。
- 安装、更新断了再试时，已经下好的文件不再重下，只下没下完的（文件留在平台文件夹的 apps\.objects，装好后删掉，没人再试的一周后删）。
- 旧版本和没装完的文件夹删得掉了：以前工具共用的 Electron 文件只要有程序开着，平台就删不掉放着这些文件的旧版本，越积越多（apps\platform 里留着 0.9.6 到 0.9.13）。现在删得掉的立刻删，一时删不掉的先挪进 apps\.trash，下次启动平台再删。还有程序在运行的旧版本不删，等它关了再删。
- 「环境」页更新 Claude Code 时真的换成新版了：以前 Studio 里有 Claude 会话开着时，点「更新到 2.1.317」后还是 2.1.316，页面一直提示有新版（Claude Code 自己的安装程序换不了正在运行的启动程序，却照样说装好了）。现在平台会把旧的启动程序挪开、放上新版；开着的会话继续用旧的，新开的就是新版。挪开的旧文件等没有 Claude 在用时再删。
- 登录后、打开平台时「正在连接」不再要等十秒多：查看哪些工具在运行的那一步换了个快的办法（这台电脑上从 11 秒变成不到 1 秒）。

## 0.9.20（2026-11-03）

- 平台更新自己时不会再报「下载 … 中途断了（terminated）」了：平台窗口里下载较大的文件时，已经在收的连接会被提前回收掉（同样的下载在窗口外从不出错）。现在下载一直保持到文件写完；真断了会自动从头再下两次，还不行时报错里写出具体原因。

## 0.9.19（2026-11-03）

- 程序包瘦身：平台自己的程序文件夹从 414 个文件减到 355 个（去掉了重复的一份内部模块和类型声明）；平台装的 Studio、Reviewer、便签、中转也各自瘦了（Studio 从 11230 个减到 4396 个）。用起来没有变化。

## 0.9.18（2026-11-03）

- 装了火绒这类杀毒软件的电脑上，更新不会再报「EPERM, Permission denied: …\.partial-…」了：杀毒软件会马上打开刚下载的程序文件扫描，那几秒里 Windows 不让给文件夹改名，更新的最后一步就失败了。现在遇到这种情况会等一下再试（最多半分钟）。真失败时报的是最初的错误，不再是清理时的错误。

## 0.9.17（2026-11-03）

- 「环境」页可以直接安装、更新 Claude Code 和 Codex 了。每一项下面分两行：「团队服务器」（服务器上备好了版本时才有，局域网，快）和「官方」，各写着版本号，有自己的「安装」或「更新到」按钮，想从哪里装就点哪个。
- 下载断了再点一次会接着下，不用从头来。从团队服务器没下成时会说原因，可以改点「官方」那一行，下了一半的部分接着用。
- 下载时进度条显示已下多少、百分比和速度。团队服务器正在准备新版时，页面上会写出来。
- Claude Code：下 120 MB 左右的压缩包，按 Anthropic 的清单核对，对不上就不装。没装的、用官方方式装的都能在这里装；用 npm 装的还是用 npm 更新。
- Codex：照旧用 npm 安装，只是 180 MB 的程序包由平台下载（服务器或 npm 官方），按 npm 的 sha512 核对后交给 npm，npm 不再自己下这个大包。没装的、用 npm 装的都能在这里装、更新。
- Codex 的两种特殊情况：
  - 电脑上没有 npm 时，按钮是灰的，写明要先装 Node.js（自带 npm），并给出下载页。
  - 用 OpenAI 安装脚本装的独立版 Codex，平台不更新它，面板上写明了。

## 0.9.16（2026-11-03）

- 平台启动和刷新时不再下载每个工具的完整清单了（Studio 的有 2 MB 多），只读一份几百字节的版本说明（名字、改动说明）；完整清单只在真正安装、更新时才下载。连的是旧服务器时照旧读完整清单。

- 网络慢时安装、更新 Studio 不会再报「清单不对：不是 JSON 对象」了：Studio 的清单现在有 2 MB 多，以前 15 秒内没读完就被掐断，再被当成清单坏了。现在读清单最多等 2 分钟，没读完整会自动再读一次，还不行就直说「没读完整，网络慢或者断了，再试一次」。

## 0.9.15（2026-11-02）

- 「环境」页：DeepSeek Harness 桌面版装在别的文件夹也能认出来了（按 Windows 的安装记录找）。还是没找到时，提示里写明在默认位置和安装记录里都找过，并说可以在 Studio 的 设置 → 模型 → DeepSeek Harness 里选它的文件夹。

## 0.9.14（2026-11-02）

- 「环境」页点 Claude Code 或 Codex 的「更新」后，下面会显示一条进度条和「正在运行 npm install -g …，已 N 秒」，不再只是按钮变成「正在更新…」看不出还在不在跑。npm 和 claude update 不报百分比，所以进度条只表示还在做，最多等 5 分钟。

## 0.9.13（2026-11-01）

- 托盘菜单的「AMO 便签」下多了「显示待办」（便签设置里开着「使用待办」时）和「便签设置…」：平台启动的便签没有自己的托盘图标，以前从托盘打不开便签的设置。

## 0.9.12（2026-10-30）

- 「工具」页点 Studio 的「关闭」不再误报「正在运行的 AMO Studio 是 0.9.7 打开的……请用托盘右键完全退出」：以前只要旧版本文件夹里还有它带起来的程序在跑（例如 Studio 让模型用的 claude.exe、随它启动的便签），就算成旧版本。现在先问正在运行的 Studio 自己是哪个版本，问不到时才看进程，而且只看 Studio 本身的程序。

## 0.9.11（2026-10-30）

- 窗口切回前台时不再每次都显示「正在连接」、把「更新到」「安装」变灰：已经连上过的话，在后台重新问服务器，期间照旧显示上次的结果、按钮照常能点，问到了再换成新的，连不上才改成连不上。切回前台时距上次问服务器不到 1 分钟就不再问（本机哪些工具在运行照样每次都查）；点「刷新」照常立刻问。「正在连接」只在刚打开、刚登录、之前连不上时出现。

## 0.9.10（2026-10-30）

- 正在连接服务器时，「工具」页每个工具的状态写「正在读取服务器上的版本…」，不再显示上一次的结果（刚打开平台时已装的工具会误写「这个通道里没有它」）。这时「安装」「更新」灰着，鼠标停上去写「正在连接服务器…」；「打开」「关闭」「回到上个版本」「卸载」照常能用。

## 0.9.9（2026-10-29）

- 中转有等你处理的会话或没读的聊天时，托盘图标换成中转的图标并带数字闪烁，单击直接打开中转；清零后换回平台的图标。托盘菜单里写「打开中转（N 条待处理 / 未读）」。要中转也更新到 0.9.4。

## 0.9.8（2026-10-29）

- 托盘菜单换成和便签一样的样式（AMO 的方角小窗），单击图标会打开的那一项是粗体。
- 设置里可以选主题：浅色、深色、跟随系统。平台的窗口和托盘菜单都跟着变。
- 下载、更新时的进度条只往前走，不再涨了又退回去。
- 工具卡片上的「关闭」：正在运行的工具如果比 Studio 0.9.8、便签 0.9.3、中转 0.9.2 旧，还不认识「关闭」，会说明要用它自己托盘里的「完全退出」或「退出」，不再只是把它的窗口叫到前面。

## 0.9.7（2026-10-29）

- 托盘只剩平台一个图标：从平台打开的 Studio、便签、中转不再各放一个，平台的托盘菜单按工具分区列出全部操作（打开 Studio、完全退出 Studio、显示 / 隐藏便签、退出便签、打开 / 退出中转……）。单击托盘图标打开便签或 Studio，在菜单最下面选；打开平台在菜单里。
- 工具正在运行时，卡片上多一个「关闭」。关 Studio 和它自己的「完全退出」一样，有会话在跑会先问。
- 环境页显示 Claude Code 和 Codex 的最新版本，有新版时可以点「更新」（按原来的安装方式：npm 或 claude update）。Codex 被 Studio 占着时会说先完全退出 Studio。

## 0.9.6（2026-10-29）

- Studio 卡片显示后台是否在运行、有几个会话、是哪个版本；装了新版但后台还是旧版时，可以点「重启 Studio」（有会话在跑时要等它们停下）。

## 0.9.5（2026-10-28）

- 平台和它装的工具都放在你解压平台的那个文件夹里，不再搬到 AppData；平台更新后，外面的 AMO Platform.exe 会自己换成新版；放在不能写入的文件夹时，会提示把整个文件夹移走。
- 左栏底部新增「账号」：在这里改昵称、头像和负责什么，退出登录也挪到这一页。
- 工具卡片上不再直接显示「回到上个版本」，它和「卸载」一起收进「⋯」菜单。

## 0.9.4（2026-10-28）

- 「工具」里可以安装和更新 AMO 中转；从平台打开中转时自动带上团队服务器的地址。
- 读取登录密钥和查看正在运行的程序时，不再使用会被杀毒软件误报的 PowerShell 写法。

## 0.9.3（2026-10-28）

- 平台能自己更新了：有新版时顶栏提示，在「设置 → 平台更新」里看改动说明、点「更新平台」，装好后点「重启平台」换成新版，从平台打开的工具不会关。
- 从下载页解压出来的平台，第一次更新后会装进 AMO 文件夹并从那里启动，开机启动也跟着改过去，原来解压的文件夹可以删。

## 0.9.2（2026-10-28）

- 新增「环境」页：检测 Claude Code、DeepSeek Harness 桌面版、Codex、git 装没装、版本和用途，没装或要注意的项可以一键打开官方下载页（Claude Code 另给 PowerShell 安装命令和复制按钮）；只检测、不替你安装。
- 工具共用一份 Electron：装第二个工具时，本机已有的文件直接用，不再重新下载；几个工具一共只占一份 Electron 的空间。

## 0.9.1（2026-10-28）

- 登录页可以注册：没有账号的人在平台上直接注册团队服务器的账号，服务器设了邀请口令时要填口令，注册好直接进「工具」页。
- 下载压缩：服务器上的文件压缩存放，安装和更新下载的量大约只有原来的一半。
- 新图标：取景框里一个橙色的田字格加号，托盘里用专门的小图。

## 0.9.0（2026-10-28）

- 第一版：托盘常驻，用团队服务器的账号登录。
- 「工具」页：列出服务器上发布的 AMO Studio、Reviewer、便签，能安装、打开、更新、回滚、卸载，显示下载进度和改动说明。更新只下载变了的文件，没变的直接从上一版带过来。
- 「目录」页：工具装在哪；Studio 数据目录（第一次从平台打开 Studio 前要先设）。
- 「设置」页：服务器和账号、更新通道（稳定 / 测试）、开机启动。启动参数 `--channel test` 和选「测试」一样。
