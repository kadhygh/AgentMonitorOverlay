# AMO Reviewer 改动说明

每个版本一节，标题写 `## 版本号（日期）`。发布到团队服务器时（`npm run relay:mac -- publish reviewer`），这一节就是平台上显示的改动说明。

## 0.9.1（2026-10-28）

- 有了自己的图标：取景框里的绿色放大镜（原来借用 Studio 的）。

## 0.9.0（2026-10-22）

第一个发到团队里的版本（独立版；AMO Studio 里带的是同一份）：

- Git Review：看未提交的改动、对比某个分支、看某个提交；「历史」里挑提交；只看改动 / 完整文件、diff 模式。
- 查看器：打开文件并定位到行；Markdown 和 HTML 渲染后显示，段落可以直接批注，HTML 还能右键在任意位置批注；页面里的链接能直接跳转。
- 写好批注后「复制注释」或「复制并关闭」，贴回给需要的人或模型。
- 命令行打开（任何工具或模型都能调用），已经开着时由开着的那个打开；键盘操作都标在按钮上。
- 数据在 `%APPDATA%\AMO Reviewer`。
