# AMO Reviewer 改动说明

每个版本一节，标题写 `## 版本号（日期）`。发布到团队服务器时（`npm run relay:mac -- publish reviewer`），这一节就是平台上显示的改动说明。

## 下一版

- 程序包瘦身：程序文件夹里的文件从 11144 个减到 4344 个，第一次安装和每次装新版要建的文件少了一大半。去掉的是重复的一份内部模块、类型声明、source map，以及第三方包里的说明文档、测试和示例；各包的许可证照留。用起来没有变化。

## 0.9.10（2026-10-31）

- 写批注都改成在旁边弹一个小窗，不再写在侧栏或插在代码行中间：渲染的 Markdown/HTML 选中文字点「批注」或右键「在这里批注」，小窗出现在选中的地方旁边；源码和改动里点行号旁的「+」，小窗浮在那一行下面，下面的代码不会被挤开；点「编辑」改已有的批注也在小窗里。右边的「批注」栏照旧列出写好的批注。（问题 #2）
- 批注小窗按住标题能拖开，拖右下角能调大小；每次打开还是原来的大小。（问题 #2）

## 0.9.9（2026-10-31）

- 查看器和 Git Review 窗口右上角、最小化按钮左边多了一个图钉按钮「置顶」：点一下窗口就一直在其他窗口上面，再点一下取消。查看器的默认宽度加宽了一点，给它腾位置。（问题 #3）
- 查看器和查看包窗口里的「固定」改名叫「锁定」（锁定后这个窗口保留，之后点开的文件在新窗口里打开），免得和「置顶」混淆。（问题 #3）

## 0.9.8（2026-10-29）

- Git Review 和查看器的窗口不再用 Windows 自带的标题栏，和 AMO Studio 一样由 AMO 自己画：最上面一行可以拖动窗口，右上角是最小化、最大化、关闭。

## 0.9.7（2026-10-29）

- 可以选主题了：Git Review 窗口顶栏最右边的按钮，在浅色、深色、跟随系统之间切换，所有 Reviewer 窗口一起变。Studio 里带的 Reviewer 照旧跟着 Studio 的主题。

## 0.9.6（2026-10-29）

- 查看器里的 Markdown 会显示文件旁边的图片。

## 0.9.5（2026-10-29）

- 跟着 Studio 的后台一起更新，用起来没有变化。

## 0.9.4（2026-10-29）

- 跟着 Studio 的后台一起更新（新的托盘退出接口、远程配对用的模块），用起来没有变化。

## 0.9.3（2026-10-28）

- 去掉了会被部分杀毒软件误报成木马的 PowerShell 写法。

## 0.9.2（2026-10-28）

- 和平台里的其他工具共用一份 Electron。

## 0.9.1（2026-10-28）

- 有了自己的图标：取景框里的绿色放大镜（原来借用 Studio 的）。

## 0.9.0（2026-10-22）

第一个发到团队里的版本（独立版；AMO Studio 里带的是同一份）：

- Git Review：看未提交的改动、对比某个分支、看某个提交；「历史」里挑提交；只看改动 / 完整文件、diff 模式。
- 查看器：打开文件并定位到行；Markdown 和 HTML 渲染后显示，段落可以直接批注，HTML 还能右键在任意位置批注；页面里的链接能直接跳转。
- 写好批注后「复制注释」或「复制并关闭」，贴回给需要的人或模型。
- 命令行打开（任何工具或模型都能调用），已经开着时由开着的那个打开；键盘操作都标在按钮上。
- 数据在 `%APPDATA%\AMO Reviewer`。
