# AMO Reviewer 改动说明

改动先写进「## 下一版」；发布时（`npm run release -- reviewer` 或 `auto`）它会改成 `## 版本号（日期）`，这一节就是平台上显示的改动说明。

## 下一版

- 查看 HTML 或 Markdown 时，点里面的图片（或指向图片的链接）不再把整页换成这张图：图片在页面上方放大显示，滚轮缩放、放大后可以拖动，Esc、点旁边或 × 关掉就回到原来的页面。上方有「在查看器中打开」和「在资源管理器中显示」。
- 查看器加了「←」返回：在页面里点开了别的文件，点标题栏左边的「←」（或 Alt+←、鼠标侧键）回到上一个，HTML 和 Markdown 回到原来滚到的位置。只记在这个窗口里，关掉就没了。
- 看 HTML 时，页面旁边的 CSS、脚本、图片、字体（例如 AI 生成的报告把样式写在同文件夹的 `style.css` 里）现在能加载了，页面显示得和浏览器里一样；以前只有内嵌在 HTML 里的样式才生效。能加载的是页面所在项目里的文件（不在项目里的页面：它自己的文件夹），项目外面的不加载。

## 0.9.13（2026-11-05）

- 查看文件时按 Ctrl+A 只选中代码，不再连底下的快捷键提示、按钮一起选上；接着 Ctrl+C 复制的是整个文件，不带行号，很长的文件没滚到的部分也在里面。Git Review 里 Ctrl+A 只选当前文件的改动，复制出来是带 +/- 的改动内容；Markdown、HTML 预览只选文档本身。搜索框、批注框里的 Ctrl+A 照旧只选框里的字。

## 0.9.12（2026-11-04）

- 配合 AMO 平台更快地知道 Reviewer 开着还是关了：运行时在 `%APPDATA%\AMO Reviewer` 里记下自己的进程号，退出时删掉。
- 文件的右键菜单滚动鼠标滚轮、切到别的窗口时也会关上；菜单开着时按 Esc 只关菜单。
- 对话框（书签说明等）打开时焦点在对话框里，按 Esc 只关最上面那一个，关上后焦点回到原来的位置。

## 0.9.11（2026-11-03）

- 程序包瘦身：程序文件夹里的文件从 11144 个减到 4344 个，第一次安装和每次装新版要建的文件少了一大半。去掉的是重复的一份内部模块、类型声明、source map，以及第三方包里的说明文档、测试和示例；各包的许可证照留。用起来没有变化。

## 0.9.10（2026-10-31）

- 写批注都改成在旁边弹一个小窗，不再写在侧栏或插在代码行中间：渲染的 Markdown/HTML 选中文字点「批注」或右键「在这里批注」，小窗出现在选中的地方旁边；源码和改动里点行号旁的「+」，小窗浮在那一行下面，下面的代码不会被挤开；点「编辑」改已有的批注也在小窗里。右边的「批注」栏照旧列出写好的批注。（问题 #2）
- 批注小窗按住标题能拖开，拖右下角能调大小；每次打开还是原来的大小。（问题 #2）

## 0.9.9（2026-10-31）

- 查看器和 Git Review 窗口右上角、最小化按钮左边多了一个图钉按钮「置顶」：点一下窗口就一直在其他窗口上面，再点一下取消。查看器的默认宽度加宽了一点，给它腾位置。（问题 #3）
- 查看器和查看包窗口里的「固定」改名叫「锁定」（锁定后这个窗口保留，之后点开的文件在新窗口里打开），免得和「置顶」混淆。（问题 #3）

## 0.9.8（2026-10-29）

## 0.9.7（2026-10-29）

## 0.9.0（2026-10-22）

第一个发到团队里的版本（独立版；AMO Studio 里带的是同一份）：

- Git Review：看未提交的改动、对比某个分支、看某个提交；「历史」里挑提交；只看改动 / 完整文件、diff 模式。
- 查看器：打开文件并定位到行；Markdown 和 HTML 渲染后显示，段落可以直接批注，HTML 还能右键在任意位置批注；页面里的链接能直接跳转。
- 写好批注后「复制注释」或「复制并关闭」，贴回给需要的人或模型。
- 命令行打开（任何工具或模型都能调用），已经开着时由开着的那个打开；键盘操作都标在按钮上。
- 数据在 `%APPDATA%\AMO Reviewer`。
