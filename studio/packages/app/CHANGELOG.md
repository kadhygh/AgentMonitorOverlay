# AMO Studio 改动说明

改动先写进「## 下一版」；发布时（`npm run release -- studio` 或 `auto`）它会改成 `## 版本号（日期）`，这一节就是平台上显示的改动说明。

## 下一版

## 0.9.59（2026-11-10）

- 设置 → 统计 最下面多了「按时间段查」：选开始和结束的日期、时间（精确到分钟，结束不填就是到现在），按模型列出这段时间的输入、缓存命中、输出和轮数；还有「最近 1 小时」「今天」「昨天」「最近 24 小时」几个快捷按钮。上面的图表照旧按天、周、月算。

## 0.9.58（2026-11-09）

- DeepSeek 会话不会再因为某个 MCP 连不上而整个开不起来。以前项目里开着 DSH 连不上的 MCP（比如要登录的 Figma MCP）时，新建 DeepSeek 会话或首次交互只显示「Internal error」，日志里也看不到原因。现在 Studio 会去掉这个 MCP 再开会话，会话里多一行说明是哪个 MCP、DSH 报了什么，其他 MCP 照常可用。DSH 的其他报错也会带上它给的细节，不再只有「Internal error」。
- 用 `session_start` 拉起子会话时，可以指定它开哪些 MCP、关哪些，比如 `{"playwright": true}`。以前新会话只能沿用任务里上一个会话的 MCP 开关，那边关过 playwright，子会话就用不了浏览器。Codex 的 MCP 在它启动时就定了，不能按会话设。

## 0.9.57（2026-11-09）

- 设置 → 测试功能里，还在开发的功能名字旁边多了「开发中」标签，「全景」现在带着它。另外新加了一项「脉络」（也是开发中）：以后一个会话里同时推进几件事时，用它记下每条线做到哪、还欠什么、在等谁，上下文压缩了也不丢。这一版只有开关，打开后还没有入口。

## 0.9.56（2026-11-09）

- 项目里开着 SSE 连接的 MCP（比如 gorilla-canvas）时，DeepSeek 会话也能开起来了。以前 Studio 把它原样交给 DeepSeek（DSH），DSH 不支持 SSE，直接报「Invalid params: mcpServers[…] transport sse is not supported」，整个会话起不来，用 `session_start` 拉起的 DeepSeek 子会话也一样，只能去关掉项目里的 MCP。现在 DeepSeek 会话只带 DSH 支持的 MCP，带不上的不带，会话里多一行说明是哪个、为什么没带；其他 MCP 照常可用，DSH 以后支持了会自动带上。Codex 本来就带不上 SSE 的 MCP，以前是不声不响地跳过，现在新会话里也会说明。Claude 会话不受影响。

- 任务页顶上中转的那几行不再一直挤占空间。超过一行时只显示第一行，后面接着「还有 N 条中转」，点开看全部，「收起」再折回去；等你点「发送」的中转卡片照常全显示。「✓ 某某 已接手…，不用回复」这一行多了「知道了」，点了就不再显示，看板卡片上也一起消掉（按这台电脑记住）；没点的照旧一天后自己消失。

## 0.9.55（2026-11-09）

- DeepSeek 用 DSH 桌面版登录的账号时，也能查余额了。以前内置的 DeepSeek 只会用 API Key 查余额，选了账号登录、没存 Key 时，左下角额度和 设置 → 额度 只显示「还没有保存API Key」。现在按 设置 → 模型 → DeepSeek 里选的登录方式去查：选了账号，就用桌面版的登录去 DeepSeek 开放平台查这个账号的余额（充值加赠送）；选了 API Key，照旧用 Key 查。换了登录方式，余额跟着重查。账号的登录只发给 platform.deepseek.com，登录过期时提示去 DSH 桌面版重新登录。

## 0.9.54（2026-11-09）

- Claude 的计划改到自己的窗口里审。以前计划在对话里是一大段文字，不能写批注，要修改还得回到对话的输入框去写。现在对话里只有一行「Claude 的计划：标题」和「查看计划」按钮（之前的版本、已批准的也能随时打开看），输入框上面的条只剩「打开计划」和「批准并开始」。计划窗口每个会话一个：选中计划里的文字可以写批注（和回复的批注一样，高亮、点高亮能改）；下面有自己的输入框写要修改的地方，和「复制批注 / 先不批准 / 要修改 / 批准并开始」。点「要修改」时输入框的话和批注一起发给 Claude；没写字、只有批注也行。输入框里写到一半关掉窗口，再打开还在，发出去才清空。窗口开着时 Claude 交来新的一版，窗口自动换到新的一版，标题栏能切回之前的版本。计划的批注只跟着「要修改」发，不出现在任务页的批注栏里。在别的设备上远程用的会话，计划还是原来的样子。

## 0.9.53（2026-11-09）

- GPT（ChatGPT 登录）的用量又能读出来了。Studio 开着久了，ChatGPT 的登录凭据会过期，以前展开额度时显示「读不到用量：… 401 Unauthorized … token_expired」。现在读到过期时先让 Codex 刷新登录凭据，再读一次用量；刷新也不成功才显示原来的错误。
- 每轮回复下面、用量旁边的时间前面加了日期，比如「11-09 00:49」；不是今年的再加上年份。以前只有时分，翻到前几天的回复看不出是哪天。
- 远程用任务时能看到项目了。这台电脑在别的设备上用的任务，看板卡片、任务页标题下面都写着它在那台电脑的哪个项目里（比如「在 A 台式机 上 · 游戏客户端」），会话顶上那一行也写着这个会话的项目；那边的项目改了名，这边跟着变。授权给别的设备的任务，在「远程」里那一行也写着项目。只传项目的名字，不传文件夹路径。那台电脑要升级到这一版才会发项目名，没升级的时候这边不显示。
- 会话顶上那一行（模型右边）现在写着这个会话在哪个项目里，公共目录写「未指定项目」。一般和任务的项目一样，用 `session_start` 开在别的项目里的会话，这里写的是它自己的项目。窗口窄的时候项目名先缩，最多只剩文件夹图标，鼠标停上去能看到全名。
- 点了停止、几秒内又发了一条消息时，新的这一轮不会再在停止 15 秒后被掐断。停止本身是马上生效的；15 秒是 Claude 或 DSH 没回应停止时的兜底（关掉它的进程），以前它只看「会话是不是还在跑」，没分清是不是被停下的那一轮，于是把紧接着发的新一轮当成没停下，关掉了进程（会话里还会多出「点了停止 15 秒后 Claude 还没停下」和「Host 关闭时这条会话的回复被中断了」两行）。现在只对被停下的那一轮生效。Codex 本来就是这样，没有这个问题。
- 你点了停止的会话，期间别的会话、中转、值守转来的消息，在你发下一条消息时会随它一起送进去（排在它后面）。现在这条转来的消息下面写「已随你刚发的消息一起送进去，模型接下来会读到」，不再显示「立即发送」。以前它写「等待送达」并带着「立即发送」，看着像还没送，一点反而打断了你刚发的那一轮。会话里那行说明也改成「等你发下一条消息时，排在它后面一起送进去」。另外修了一处：转来的消息正在送的时候你刚好发了消息，它们以前要等这一轮做完才送，现在也随你的消息一起送。
- 别的会话用 `session_start` 以只读方式开的 Claude 会话，不再找你审批计划。Claude 的只读用的是计划模式，以前它做完会把结果当成「计划」交给你批，你批完它又把同样的内容写一遍回复转给开它的会话，而且批准后这个会话就不再是只读了。现在 Studio 一开始就告诉它直接写回复交回，它要是还提交计划，Studio 直接替你拒掉，会话保持只读。人自己开的、或「替人开」的会话照常审批计划。

## 0.9.52（2026-11-07）

- Codex 会话不再带 Codex 桌面版的浏览器控制和电脑控制（Browser、Chrome、Computer Use 插件和 `node_repl`）。这些工具要 Codex 桌面版在旁边当宿主才能用，Studio 的会话里一用就报「The browser access host is unavailable」或「native pipe 不存在（os error 2）」，每个会话还会白起几个 node 进程。现在 Studio 启动 Codex 时会把它们关掉，只影响 Studio 里的会话，Codex 桌面版里照常能用。要让 AI 在 Studio 里控制浏览器，在「设置 → MCP」里加一个浏览器 MCP（比如 Playwright MCP），Claude、Codex、DeepSeek 的会话都能用。改动在 Codex 下次启动时生效。

## 0.9.51（2026-11-07）

- DeepSeek（DSH）会话：模型的回答传到一半、连接被对面正常关掉时（报错「DeepSeek Messages stream ended before message_stop」，常见于中转渠道），现在会自动重新请求，不再让整个回合直接失败。和断网、超时一样，最多重试 5 次；被截断的半段回答丢掉，不会出现在对话里，也不会重复执行命令。代价是这一段回答要重新生成。
- DSH 的子 agent 失败时，它的会话里会多一行错误，写明原因（以前只显示「处理失败」，原因看不到）。被父会话停下、被钩子停下、输出到上限、主会话的 DSH 进程结束等其他原因停下时，也会多一行说明是什么停下了它。

## 0.9.50（2026-11-07）

- 查看器里看渲染后的 HTML 时也能 Ctrl+F 查找了（以前只有 Markdown 和源码能查）：在页面里或窗口任何地方按 Ctrl+F 打开查找栏，选中的一行字会自动填进去；显示「第几个 / 共几个」，回车下一个、Shift+回车上一个，「Aa」区分大小写，Esc 关掉。找的是页面上看得见的文字，折起来的 `<details>` 里的也算（跳到时自动展开），脚本和隐藏的部分不算；匹配的字标黄，当前这个标橙，页面本身不会被改动。

## 0.9.49（2026-11-06）

- Focus 里点开一张卡片（会话卡片展开详情，或点「▸ N」展开子 agent），列表会自动滚到让这张卡片完整显示，下面的「批准」「在工作台打开」等按钮不用再手动往下滚；卡片比列表还高时，保证它的开头在视野里。详情是展开后才加载的，所以展开后 1.5 秒内会跟着它变高继续调整，这期间你自己滚动滚轮就不再跟。

## 0.9.48（2026-11-06）

- Focus 标题栏的设置按钮换成齿轮图标（和主窗口左下角的「设置」一样），以前那个像太阳。
- 「Focus 设置」里加了「拖拽调整大小」开关：打开后面板撑满整个 Focus 窗口，外面一圈虚线框，左上角有一个角标，拖它就能改大小（右下角不动，往左上拖变大）；改好的大小下次启动还在。点面板上的「完成」或在设置里关掉开关，就不能再拖。开关开着时 Focus 会像「移动位置」时一样能拿到焦点，所以开关本身不记住，重启后是关的。窗口拖得很矮时，「Focus 设置」框可以滚动，开关始终点得到。
- 机器人等太久生气乱飞时，鼠标追上它（指针停在机器人或它的气泡上）它就停下，方便点它；指针离开 1.5 秒后接着飞。每帧多读一次鼠标位置（实测约 1.5 微秒，每秒 30 次），停住时还省掉了挪窗口（约 2 毫秒一次），所以比原来更省。

## 0.9.47（2026-11-06）

- 「选择文件夹」窗口加了「在这一层里找」：输入文件夹名字的一部分（不分大小写），列表只留名字里含它的文件夹，匹配的字标出来，第一个自动选中，回车打开、↑↓ 换选。只找当前显示的这一层，不往下层找。在列表上直接打字、或按 Ctrl+F 也会进到搜索框；进了别的文件夹搜索就清空；Esc 先清空搜索，再按一次才关窗口。

## 0.9.46（2026-11-06）

- 查看器（和查看包）里看 HTML 或 Markdown 时，点里面的图片（或指向图片的链接）不再把整页换成这张图：图片在页面上方放大显示，滚轮缩放、放大后可以拖动，Esc、点旁边或 × 关掉就回到原来的页面。上方有「在查看器中打开」和「在资源管理器中显示」。
- 查看器加了「←」返回：在页面里点开了别的文件，点标题栏左边的「←」（或 Alt+←、鼠标侧键）回到上一个，HTML 和 Markdown 回到原来滚到的位置。只记在这个窗口里，关掉就没了。
- 查看器里看 HTML 时，页面旁边的 CSS、脚本、图片、字体（例如 AI 生成的报告把样式写在同文件夹的 `style.css` 里）现在能加载了，页面显示得和浏览器里一样；以前只有内嵌在 HTML 里的样式才生效。能加载的是页面所在项目里的文件（不在项目里的页面：它自己的文件夹），项目外面的不加载。远程任务的页面也一样：样式、脚本、图片从被控端取来；字体要被控端也更新到这一版才能取到。

## 0.9.45（2026-11-06）

- DeepSeek（DSH）会话自己用 `subagent` 开的子 agent 现在能看到了：以前只有一行，一开始就显示「完成」，子 agent 做了什么一行都看不到。现在和 Claude 的子 agent 一样，在父会话下面挂一个子会话，里面边跑边显示它收到的任务、思考、命令、回复；父会话里那一行显示它的状态（◐ 进行中、✓ 已完成、! 已中断、! 出错了）和用量，它发回结果时父会话里也有一行。子会话不能单独发消息，要在父会话里继续。Claude 子 agent 的那一行也会显示状态。DSH 要等子 agent 都跑完这一轮才结束，这期间发的消息会显示「等子 agent 跑完后送到」；不想等的话，让它用 AMO 的子会话开子 agent。
- 设置 → 功能里新增「命令行适配（Windows）」，默认开着：agent 跑的 Python 按 UTF-8 输出中文（Studio 给 Claude、Codex、DeepSeek 设置 `PYTHONUTF8`、`PYTHONIOENCODING`，你自己设过的以你的为准），AMO 给 agent 的说明里多几条 Windows 命令行的注意事项（Bash 里路径用正斜杠；带反斜杠、正则、多层引号的脚本写成文件再跑；PowerShell 里不用 bash 写法，读写文件带 `-Encoding utf8`）。起因是翻了本机的会话记录：Windows 上最常见的命令失败是中文乱码（Claude 的 Bash 里 469 次，Codex 5、6 月 6,700 多次），其次是引号和反斜杠。关掉后，之后新开的会话就不带这些；Codex 要等它下次启动。
- 远程任务的任务页上直接显示被控端的模型额度：那台电脑已经读到过这个模型的额度（Claude、GPT 的用量窗口，或渠道余额），收起时在模型名旁边列出每个窗口，各带一根小进度条和已用的百分比（例如「5 小时 ▬ 37% · 每周 ▬ 12%」，鼠标停上去看剩多少、多久重置；窗口窄时先省掉进度条），没有窗口的渠道写余额；展开说明后用和左下角额度一样的完整进度条显示每个窗口剩多少、多久重置，并写明「A 台式机 上的数据 · X 分钟前更新」。被控端只发它已经有的数字，额度有变化时自动发过来，不会为这边去查或刷新；没读到过的模型什么都不显示。同一个账号登录的设备（你自己的另一台电脑）默认能看；别的账号的设备默认看不到，要在被控端的「远程」→ 已配对的设备里，给那台设备勾上「让它看我的模型额度」，取消勾选后那边立刻清掉。两台电脑都要更新到这一版才会显示。

## 0.9.44（2026-11-05）

- 中转的回复转回会话时，回复附上的批注写成和 Reviewer 复制一样的样子（文件名和版本、`>` 后面是引用的原文、下面是批注内容和写的人）。
- 任务页顶上等中转回复的那条，现在每个会话一行，旁边有「在中转里打开」（装了中转时）：启动中转（开着就叫到前面）并打开那个会话。
- 对方在中转里点了「已接手，不用回复」：任务页和看板卡片上显示「✓ X 已接手「标题」，不用回复」（一天内），不再显示在等。会话默认不会收到任何消息；只有对方勾了「把附言转给 AI」时，附言作为一条【中转回复】送进会话。
- 中转里会话头上的「在 Studio 里打开」能让 Studio 跳到发起那个会话的对话（Host 新增 `POST /api/ui/open`；Studio 开着时在 `%APPDATA%\AMO Studio\running.json` 记下自己的数据目录，退出时删掉，中转靠它找到开着的 Studio）。

## 0.9.43（2026-11-05）

- 会话用「等你决定」问你（卡片上写「非阻断 · 留言返回」的那种，GPT、DeepSeek 常用），你回答得晚、它这一轮已经结束了，回答不再石沉大海：以前回答只放进留言箱，没人去读，会话一点反应都没有。现在这一轮还在跑时，回答照旧作为留言，模型可以自己去读；这一轮已经结束，或者结束时它还没读，回答会作为一条消息发进会话，写明是对哪个问题的回答，模型接着处理。
- Codex 自己停掉一轮（比如在终端里停的）时，那一轮里还没回答的问题记成「提问已取消」，不再错写成「已在别处回答」。
- 查看器、Git Review、查看包里按 Ctrl+A 只选中文件内容，不再连快捷键提示、按钮一起选上；查看代码时接着 Ctrl+C 复制的是整个文件（不带行号，没滚到的部分也在），改动视图复制的是带 +/- 的改动内容。输入框里的 Ctrl+A 照旧。
- 新建任务页的第一句话里也能 @ 出「开子会话…」了：以前只有会话的输入框里有。选好的子会话设置跟着草稿存着，离开页面再回来还在；任务开始后，第一个会话照它开子会话。带着子会话设定的任务不能「放进待办」，会提示先去掉或直接开始。
- 「开子会话」弹窗重做：选了模型，下面就是这个模型自己的选项——思考强度按它的档位，有 Fast 的型号多一个 Fast 开关；能看到你在 设置 → 子会话 里给它写的用法，还能写一段「这一轮补充」，原样交给子会话。权限收进「更多」。「结果回到这个对话」去掉了：要不要结果回来由开子会话的模型自己定。
