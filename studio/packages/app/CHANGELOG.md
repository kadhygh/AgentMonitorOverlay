# AMO Studio 改动说明

每个版本一节，标题写 `## 版本号（日期）`。发布到团队服务器时（`npm run relay:mac -- publish studio`），这一节就是平台上显示的改动说明。

## 0.9.3（2026-10-28）

- 去掉了会被部分杀毒软件误报成木马的 PowerShell 写法。
- agent 进程不再降低磁盘优先级（只能靠会被误报的底层调用），CPU 和内存优先级照旧降低。

## 0.9.2（2026-10-28）

- 从平台装的 Studio 不经过平台打开时（比如固定到任务栏），也会用平台里设的 Studio 数据目录。
- 和平台里的其他工具共用一份 Electron。

## 0.9.1（2026-10-28）

- 新图标：取景框里的蓝色笑脸，和 AMO 的其他工具成一套。
- 数据库被更新版本的 Studio 用过时，拒绝打开并说明原因；启动失败时都会弹窗说明，不再一声不响地退出。
- 设置 → 维护：可以开 Codex 终端（源码启动时才有）。

## 0.9.0（2026-10-22）

第一个发到团队里的版本，包含到这次发布为止的全部内容：

- 工作台：项目和任务看板（项目、专题都能分组），任务页里和模型的会话，专题上方的画布（引用卡片、颜色、右键菜单、画布审阅的问题）。
- 模型：Codex（每条命令都先问你）、Claude（只用你本机 Claude Code 的登录）、DeepSeek（DSH）；设置里有各渠道的额度和「统计」页（按天、周、月看 token）。
- 会话：委派会话和子代理都能展开看；停止、中断、自动审批、提问弹窗都在会话里处理；@ 快捷指令（如「@快速提交」）。
- Focus 小窗：AMO 娘、待确认的事、固定的会话，点一下跳到对应位置。
- 自带 Git Review 和查看器：Markdown、HTML 渲染后可以直接批注，HTML 还能右键在任意位置批注；书签、查看包。
- 自带 AMO 便签：随 Studio 启动，在托盘里。
