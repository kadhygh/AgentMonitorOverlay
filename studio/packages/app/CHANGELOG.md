# AMO Studio 改动说明

每个版本一节，标题写 `## 版本号（日期）`。发布到团队服务器时（`npm run relay:mac -- publish studio`），这一节就是平台上显示的改动说明。

## 下一版

## 0.9.20（2026-10-31）

- 查看器和 Git Review 窗口右上角、最小化按钮左边多了一个图钉按钮「置顶」：点一下窗口就一直在其他窗口上面，再点一下取消。查看器的默认宽度加宽了一点，给它腾位置。（问题 #3）
- 查看器和查看包窗口里的「固定」改名叫「锁定」（锁定后这个窗口保留，之后点开的文件在新窗口里打开），免得和「置顶」混淆。（问题 #3）
- 工作台顶栏的「置顶」按钮去掉了，工作台窗口不再浮在其他窗口上面；以前开着置顶的，更新后打开也不再置顶。查看器和 Git Review 的置顶还在。（问题 #4）

## 0.9.19（2026-10-31）

- 维护值守：你在问题下回复后，值守接着在原来处理这个问题的会话里做，不再另开一个新会话。原来那个会话还在、没归档、没在跑时才接着用；同时还有新问题或该打包时，照旧开新会话。
- 值守开的会话挂在设这个值守的会话下面（和 session_start 开的子会话一样），名字是「#问题编号 问题标题」，比如「#1 远程任务里，控制端按@什么都出不来…」；只打测试包的会话叫「打测试包」。
- 新任务页选「在别的设备上」时，「第一句话」里打 @ 能用那台电脑的提示词模板了：列它的全局模板和当前选的项目的模板（不列这台电脑自己的），选中粘进输入框；这些模板只读，要改去那台电脑上改。那台电脑的 Studio 版本旧时会提示先更新。（问题 #1）

## 0.9.18（2026-10-31）

- 值守有了自己的入口：顶栏「值守 N 项开着」（有值守项时才出现，运行中带 ◐），点开看每一项上次做了什么、下次什么时候，可以开关、立即运行、跳到它开的会话。有值守的任务在看板卡片和任务头上带「值守」，值守开的会话带「值守开的」，用 AI 设了值守的会话带「设了值守」。
- 值守项选了任务时，可以指定会话在另一个项目的文件夹里跑（比如当天的维护任务，会话在值守目录里干活）；AI 的 duty_save 用 workspace 按名字或路径指定。
- 值守的「先检查」可以几样一起查（AI 用 duty_save 设，最多 5 样）：比如维护时同时看问题页和「该发布了」，有一样有事就开一个会话，发现的内容合在一起；一样没跑通会写在下面，都没跑通才算失败。
- 远程任务里的提示词模板窗口也列出那台电脑上的模板（它的全局模板和这个任务项目的），标着「在 X 上」，可以粘进输入框，要改得去那台电脑上改。两台电脑都要更新到这一版；那台是旧版时会说读不到。
- AI 设值守（duty_save）时可以按 session_start 的说法指定模型、权限（只读 / 写 / 全部）和思考强度；不写就用它自己的模型和权限，不再落到模型默认的「逐条询问」、没人看着时停在审批上。
- 设置 → 值守：编辑时「在哪个任务」里也列出打开设置后才建的任务。
- 问题页工具认得新状态「建议单开讨论」：AI 可以把太大的问题标成它；你在问题上回了话，值守的「先检查」会把它算作「你回复了」。

## 0.9.17（2026-10-31）

- 设置里新的一页「值守」：到点了让 Studio 做一件事——开一个会话（说一段定好的话，在某个任务里或每次新建任务）、跑一条命令，或者 Studio 自带的任务。时间可以是「每隔几分钟」或「每天几点」。同一项上一次还没结束就跳过这次；开会话前先看额度，快用完了换你选的备用模型，没选就跳过。列表上能看到每一项最近一次的结果和下次什么时候跑，可以「立即运行」。Studio 退出时值守也停。
- 值守项开会话时可以指定型号、思考强度和权限。没人看着时选一个不用逐条询问的权限，不然会话会停在等你批准。
- 值守项开会话前可以先检查：跑一条检查命令，或者用 Studio 自带的检查（比如「问题页有事要做」）。检查发现有事才开会话，发现的内容接在你写的那段话后面；没事就跳过，不花额度。和上次开会话时一模一样的发现不会再开一次。
- 可以直接让 AI 帮你设值守了：比如「写个脚本检查 xxx，每 30 分钟跑一次，有问题就拉起 AI 看，没问题了就停」。AI 写好脚本、建好值守项，保存时要你批准一次；列表里标着「AI 建的」。值守开出来的会话，事情做完了可以自己把值守关掉（值守项里勾上「AI 判断事情做完……可以自己关掉」）。
- 值守跑的脚本可以自己结束值守：输出一行 `AMO_DUTY_DONE`，这次跑完就把值守项关掉。如果还有别的输出，会先开会话处理这最后一次。
- AI 能读写团队服务器问题页上的问题了：列出问题、看全文和截图、回复（可以带截图）、改状态、发完测试版后标成「已发布」。用的是你在 AMO 平台里登录的账号，AI 写的会标出来。配合提示词模板「问题页值守」和一个值守项，就能定时修问题页上报的问题。
- 提示词模板：常开的同一类任务，把提示词存成模板。在输入框里打 @，「AMO 扩展功能」下选「提示词模板…」，弹出的窗口里搜索、看内容，回车或「粘进输入框」就把这段话放进来，看过再发。模板在这个窗口里新建、编辑、删除；可以全局用，也可以只在某个项目里出现。也可以在对话里让 AI 帮你存（「把下面这段存成提示词模板」），它存的标着「AI 写的」；AI 删模板要你批准。会话的输入框和新建任务页都能用。
- 扩展包（项目里的 `.amo/packs`）删掉了：项目的「扩展包」页、任务页的「按扩展包预设」和规范文档、新建任务的「流程模板」、编辑项目里的「一键忽略 .amo/」都没有了，设置 → 功能里也不再有这一项。项目里已有的 `.amo/` 文件夹不会被动，可以自己删。以前从流程模板来的任务清单照样显示、照样能勾。

## 0.9.16（2026-10-31）

- 远程任务可以在控制的这台电脑上改名了：点任务名或会话名改，改到那台电脑上，两边一起变。那台电脑不在线或授权已收回时不能改。状态、说明、专题照旧只能在那台电脑上改。要两台电脑都更新到这一版。
- 远程任务的会话在控制的这台电脑上也有「归档」了：归档到那台电脑上（从它开出的分支一起），之后可以在这边「恢复会话」。归档整个任务照旧只是删掉这台电脑上的副本，那边的任务不动。要两台电脑都更新到这一版。
- 回复里的编号列表不再断成好几段、每段从 1 数起：某一项下面空一行再写子列表或一段缩进的话时，以前从这里断开，后面的「2.」「3.」各自变成「1.」；现在算同一个列表，缩进的那段话显示在这一项下面。单独以「3.」开头的列表也照原来的编号显示。

## 0.9.15（2026-10-30）

- 远程任务里点对话中的文件链接：AI 写的相对路径如果是从子文件夹算起的（比如在 `studio\` 里写 `screenshots/…`），以前那边会说「找不到这个文件」；现在和本机一样，按路径的结尾在任务文件夹里找，只有一个对得上就打开。要被控的那台电脑更新到这一版。

## 0.9.14（2026-10-30）

- 远程：在被控的电脑上改「远端允许的项目」「远端允许的模型」或「安全」并保存后，另一台电脑开着的新任务页（在别的设备上）马上换成新的选项，不用再切换设备或重开页面；那边的项目改名、专题新建或归档、模型渠道变动也一样。已经选好的项目、专题、模型还在的话保持选中。两台电脑都要更新到这一版。
- 远程授权的任务：被控电脑上的模型渠道改名、增删后，另一台电脑上的模型名称和能选的模型跟着更新。
- 远程任务（在这台电脑上看别的电脑授权过来的任务）：
  - 发的截图和图片在对话里能看到了（以前显示不出来）。这台电脑发的图直接用本地这份；那边发的图会自动取过来存一份。
  - 能加批注了：选中回复里的文字加批注，发出去就是一条普通消息，在那台电脑上跑。
  - 任务页上方的「在 … 上运行」改成一行：「远程」标记、在哪台电脑上、这个任务用的模型和现在的状态（运行中、空闲、待批准…）；说明默认收起，点一下展开，展开后的文字和标题对齐，和下面的会话区之间也留了空。
- 设置 → 项目与目录 → DSH 沙箱权限：已经归档、但文件夹还留着 DSH 权限的项目也列出来，标着「已归档 · 权限还没恢复」，可以直接「恢复原来的权限」；摘要那行会提醒有几个。
- 会话里 AI 跑的命令不再带上 Studio 自己的环境变量（`ELECTRON_RUN_AS_NODE`、`AMO_STUDIO_*`）：在 AMO 里让 AI 开发 AMO 时，它跑的 e2e、开发版 Studio 不会再起不来，或者连到正在用的这份 Studio 的数据和界面。新开的会话生效（Codex 要等它的后台重启）。

## 0.9.13（2026-10-30）

- AI 不再自己决定用画布：你说了（比如「主控用画布展开任务」「放到画布上审阅」）它才用，用的时候照以前一样排好分组、依赖、颜色，或者铺好审阅条目；你没说就不动画布，审阅和报告照常写在回复里。之后新开的会话生效。

## 0.9.12（2026-10-30）

- 会话里能直接用 AMO 中转找人确认了：AI 遇到要程序把关的事（实现方式、接口、工作量），会写好正文和问题，在任务页和 Focus 里等你点「发送」（自动审批模式下也要你点），发出时用你的账号、标着「AI 代发」。对方在中转里回复后，回复自动回到原来的会话、开新一轮接着做，不用再复制粘贴；还没问清楚 AI 会接着追问（同样先问你），敲定了就收尾。看板卡片和任务页上写着「等 X 回复（中转）· 已等多久」。要先在 AMO 平台里登录，中转服务也要更新。不想每次都点，可以在 设置 → 功能 → 中转 里勾「AI 找人确认时直接发出，不用先问我」（默认不勾）。
- 远程功能默认关着了：要用的话在顶栏「远程」里点「打开远程功能」，关掉在 远程设置 最下面。没在 AMO 平台里登录时打不开。开关按账号记：换一个账号登录又是关着的。关掉后这台电脑不连团队服务器，配对的设备找不到它；配对、授权和远程设置都保留，再打开就恢复。**以前用过远程的，更新后也要重新打开一次。**顶栏关着时写「远程 · 关」。
- 给 AI 用的「传话」工具改名为 task_message，免得和中转混淆（用法不变）。

## 0.9.11（2026-10-30）

- 桌宠选「AMO 娘」时，任务栏上的她又是完整的了（上一版为了显得大，把耳机两边裁掉了，看着别扭）。左上角和 Focus 里的她还是上一版放大后的大小。

## 0.9.10（2026-10-29）

- 「远程」改成弹窗：顶栏的入口不变，点开盖在当前页面上，关掉就回到原来的地方。「远程设置」在弹窗右上角，是叠在上面的第二层。
- 远程设置里加了「安全」：用同一个账号登录的你自己的其他电脑，在这台电脑上建的任务直接开跑；别的账号的设备建的任务，默认先等你在这台电脑上确认（Focus 和「远程」里会出现，项目、模型都是对方选好的，点「同意并开始」才跑）。两项都能改。
- 远程任务能带图片和文件了：在别的设备上新建任务、在远程任务里发消息或新开会话时，可以粘贴截图、拖进文件或点回形针选。每个文件最多 20 MB，一次最多 60 MB，文件夹要先打包。两台电脑都要更新到这一版。
- Focus 换成和主窗口一样的样子：方角、每行前面写着状态（! 批准、◐ 运行、✓ 完成……），每件事一张卡片，左边的色条表示状态。Focus 里不再显示模型额度（设置 → 额度 里的 Focus 一栏也去掉了）。
- 书签、画布小窗、Git Review、查看器、首次设置的窗口不再用 Windows 自带的标题栏，和主窗口一样由 AMO 自己画，右上角是最小化、最大化、关闭。
- 画布：右上角有「侧栏」开关，侧栏左边缘可以拖宽窄（双击恢复）。「详情」不在侧栏里了：单击卡片、分组或审阅条目，旁边会浮出详情框，点 ×、按 Esc 或单击空白关掉。在空白处按住拖动只移动画布，不再取消选中。
- 桌宠选「AMO 娘」时，左上角和任务栏的图标、Focus 里的她都更大了。
- 会话开出来的会话，权限默认和开它的会话一样（以前用模型的默认），也不能比它宽。Claude 会话开出的「可写」会话改成「帮我审批」，以前是「自动接受编辑」，每条命令都要你批准。

## 0.9.9（2026-10-29）

- 单独打开 Studio 时，托盘右键菜单换成和便签一样的样式。从平台打开时照旧没有自己的托盘图标。
- 带着的便签可以选主题（便签设置 → 主题）。

## 0.9.8（2026-10-29）

- 远程有了自己的一页：顶栏的「远程」按钮（写着几台设备在线，有请求时带个点），设置里不再有远程页。页面里从上到下是任务、已配对的设备、远程设置；配对设备时会列出你账号下在线的其他电脑，选一台就能发起配对。
- 新任务可以建在别的设备上：新任务页右上角切到「在别的设备上」，选设备后专题、项目、模型都是那台电脑的，回车后那边直接开跑，这边看板上出现远程任务卡。那台电脑要先在 远程 → 远程设置 里勾「远端允许的项目」和「远端允许的模型」，不用再点同意。两台电脑都要更新到这一版。
- 新任务页：专题放到项目上面，选了专题后它常用的项目排在最前（只有一个时自动选上）；每行最多显示 6 个，多的点「更多…」搜索；第一句话里的 @ 改成引用项目、任务（和它的会话）、文件，不再用来选项目，# 也不再选专题。快速启动条（Ctrl N）也一样，多了专题、项目两个选择按钮。编辑专题时可以加减常用项目。
- 从 AMO 平台打开时，Studio 不再在托盘里放自己的图标，都在平台的托盘菜单里（打开、重启、完全退出）。

## 0.9.7（2026-10-29）

- 远程任务：在这台电脑上归档远程任务时，从那边取来的文件会立刻一起删掉（以前查看器看过的图片可能删不掉）。
- 远程任务里的脚本、配置、日志这类文本文件也能点开看了；远程的 HTML 里点它引用的 md、脚本，会和本机一样接着在查看器里打开。程序和其他二进制文件仍然不能远程看，会提示。

## 0.9.6（2026-10-29）

- 远程任务对话里的 HTML、Markdown、图片可以在这台电脑上点开看（从运行任务的电脑取过来，有读条，看过的会留一份）。
- 可以请另一台电脑帮忙跑一个任务（设置 → 远程 → 已配对的设备 →「请它跑一个任务…」），那边同意后自动建任务开跑，出现在这边的看板上。
- 有任务正被远程使用时，完全退出前会提醒，电脑也不会自动睡眠。
- 查看器里的 Markdown 会显示文件旁边的图片。

## 0.9.5（2026-10-29）

- 远程：可以把任务授权给你配对的另一台电脑（任务页 ⋯ →「授权给…」）；那台电脑的看板上会出现这张远程任务卡，能发消息、审批、打断、新开会话（只能用「远端允许的模型」，在 设置 → 远程 里设）；对方在线时这个任务的提醒只在那边出现。随时能在任务页或 设置 → 远程 里收回。
- 注意：这一版升级了数据库，用过之后不能再回到 0.9.4。

## 0.9.4（2026-10-29）

- 托盘：点窗口右上角的 × 只关窗口，Studio 留在托盘里，会话继续跑；点托盘图标或再次打开 Studio 就能回来。托盘右键「完全退出」会连后台一起关，有会话在跑时先问一下会中断几个。
- 画布：卡片可以拖右下角改大小，会保存，双击恢复原样；删除分组时会问要不要连组里的卡片一起删（任务卡只从画布上拿掉，任务不删）；删除按钮和「归档」同一套配色。
- 设置 → 远程：和你自己的其他电脑配对、测试连接；配对请求也会出现在 Focus 里。需要先在 AMO 平台里登录。

## 0.9.3（2026-10-28）

- 去掉了会被部分杀毒软件误报成木马的 PowerShell 写法。
- agent 进程不再降低磁盘优先级（只能靠会被误报的底层调用），CPU 和内存优先级照旧降低。

## 0.9.2（2026-10-28）

- 从平台装的 Studio 不经过平台打开时（比如固定到任务栏），也会用平台里设的 Studio 数据目录。
- 和平台里的其他工具共用一份 Electron。

## 0.9.1（2026-10-28）

- 新图标：取景框里的蓝色笑脸，和 AMO 的其他工具成一套。
- 数据库被更新版本的 Studio 用过时，拒绝打开并说明原因；启动失败时都会弹窗说明，不再一声不响地退出。
- 设置 → 维护：可以开 Codex 终端（源码启动时才有）。

## 0.9.0（2026-10-22）
