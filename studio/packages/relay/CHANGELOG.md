# AMO 中转服务 改动说明

团队服务器上跑的中转服务（含问题页、下载页、平台的发布点）和中转客户端的界面内容。每次部署一节，标题写 `## 版本号（日期）`；部署用 `npm run release -- relay-service`，版本号也写进服务（`/api/health` 的 `version`）。

## 下一版

## 0.7.2（2026-10-31）

- 管理页 `/admin`：「服务器状态」卡片——整机和中转的 CPU、内存，在线人数和设备数，最近 24 小时的曲线；文件夹大小、磁盘、占内存最多的程序。10-31 上午部署过一次（没提交），被 0.7.1 覆盖掉了，这一版恢复。
- 下载页：「报问题」收进最下面折叠的「维护工具」里，平时只看到下载 AMO 平台。

## 0.7.1（2026-10-31）

- 问题页：新状态「建议单开讨论」（AI 觉得太大、不是顺手能修的）；新页签「要你看」：等你回答、卡住了、建议单开讨论，而且还没回的，页签上带数字。

## 0.7.0（2026-10-31）

- 从这一版开始记版本和改动说明。之前的改动见 git 记录（最近一次部署：问题页 `/issues`，提交 e483ca7）。
