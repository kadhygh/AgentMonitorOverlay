# AMO 便签 改动说明

改动先写进「## 下一版」；发布时（`npm run release -- notes` 或 `auto`）它会改成 `## 版本号（日期）`，这一节就是平台上显示的改动说明。

## 下一版

- 设置里的占用大小统一成一位小数，最大到 GB（如「12.5 KB」「1.5 MB」），和 AMO 的其他工具一样。以前 KB 取整。

## 0.9.11（2026-11-04）

- 配合 AMO 平台更快地知道便签开着还是关了：便签记下自己的进程号时也记下程序路径。

## 0.9.10（2026-11-03）

- 平台托盘里的「显示 / 隐藏便签」和便签自己托盘图标的单击，现在能把开着的便签收起来了。以前点托盘时便签会失去焦点，被当成「不在前面」，所以只会显示、不会隐藏。快捷键照旧：便签在最前面时按是收起，在后面时按是拿到前面。
- 程序包瘦身：程序文件夹里的文件从 3436 个减到 1114 个，第一次安装和每次装新版要建的文件少了一大半。去掉的是重复的一份内部模块和类型声明；用起来没有变化。

## 0.9.9（2026-11-02）

- 待办可以绑定 Studio 的任务和会话（在 Studio 里任务或会话的 ⋯ →「绑定到待办…」绑定）。绑定后待办这一条后面多一个标签，写着任务名（和会话名），点它就切到 Studio 打开那个任务或会话；Studio 没开时标签是虚线框，点了提示「打开 Studio 才能跳过去」；任务在 Studio 里已经不在了，标签变灰。每条右边的 ⋯ 里有「解除绑定」。绑定只存在这台电脑上，不传到服务器。

## 0.9.8（2026-11-01）

- 新的「待办」窗口（和便签窗口分开，可以同时开着）：托盘右键「显示待办」打开，暂时没有快捷键。要先在 AMO 平台里登录团队账号，待办存在团队服务器上：每台电脑一张自己的表（「本机」），另有一张同账号所有设备共通的表（「共通」），「其他 ▾」里能看、能改同账号其他设备的表。
  - 最上面一行直接输入、回车添加；方框勾选，做完的收进底下的「已完成」；双击或 F2 改字；拖动或 Alt+↑↓ 调顺序；每条右边的 ⋯ 可以移到别的表、复制这条、删除（删除和移动几秒内能撤销）；底栏「清除已完成」。Alt+1、Alt+2… 切表，Esc 收起。
  - 连不上服务器时照样能加、能勾，底栏写着「连不上服务器 · N 条改动待提交」，连上后自动补交；没登录时窗口里有「在 AMO 平台里登录」按钮。
- 设置窗口标题行右边显示版本号；「快捷键」下面新增「待办」一节：「使用待办」（默认开，关掉后托盘里没有「显示待办」，也不连服务器，服务器上的待办不删）、当前账号、已完成保留几天（7 / 30 / 90 天或一直留着）。

## 0.9.7（2026-10-30）

- 便签标题栏上点右键有「关于便签」：便签顶部写出版本号；从 AMO Studio 带起来的便签（没有单独安装）还写是随哪个版本的 Studio 运行的。点 × 或按 Esc 收起。

## 0.9.6（2026-10-30）

- 图片缩略图上多了「复制」（鼠标移上去出现）：只复制这一张图，便签窗口不关，可以接着复制下一张。微信这类地方一次粘贴只收文字或图片中的一样（文字和图片都有时它只要文字），要发图片就用这个。

## 0.9.5（2026-10-30）

- 「复制」（和 Ctrl+Enter）把这一页的图片也一起复制了：粘到聊天框、AMO Studio、画图这类只收一张图的地方是第一张图（加上文字，看那边收不收），粘到 Word 这类编辑器是文字加全部图片。只有图片、没有文字的页也能复制了。

## 0.9.4（2026-10-29）

- 设置里可以选主题：浅色、深色、跟随系统。便签、设置窗口和托盘菜单都跟着变，和 AMO Studio 的主题分开设。

## 0.9.3（2026-10-29）

- 从 AMO 平台（或平台打开的 Studio）启动时，便签不再在托盘里放自己的图标：显示 / 隐藏、退出都在平台的托盘菜单里；全局快捷键照旧。单独打开时照旧有自己的托盘。

## 0.9.2（2026-10-28）

- 和平台里的其他工具共用一份 Electron。

## 0.9.1（2026-10-28）

- 新图标：取景框里的黄色便签纸。

## 0.9.0（2026-10-22）

第一个发到团队里的版本（独立版；AMO Studio 里带的是同一份）：

- 托盘常驻，只开一份：左键托盘图标显示 / 隐藏，右键是菜单（设置、退出）。
- 全局快捷键默认 Ctrl+Shift+F12；Ctrl+Enter 复制当前页并隐藏，Alt+1…9 换页。
- 设置和页面在 `%APPDATA%\AMO Notes`，工作文件夹可以在设置里换；界面大小是便签自己的设置。
- 和 AMO Studio 带的便签共用同一份数据。
