# AMO 便签 改动说明

每个版本一节，标题写 `## 版本号（日期）`。发布到团队服务器时（`npm run relay:mac -- publish notes`），这一节就是平台上显示的改动说明。

## 0.9.4（2026-10-29）

- 设置里可以选主题：浅色、深色、跟随系统。便签、设置窗口和托盘菜单都跟着变，和 AMO Studio 的主题分开设。

## 0.9.3（2026-10-29）

- 从 AMO 平台（或平台打开的 Studio）启动时，便签不再在托盘里放自己的图标：显示 / 隐藏、退出都在平台的托盘菜单里；全局快捷键照旧。单独打开时照旧有自己的托盘。

## 0.9.2（2026-10-28）

- 和平台里的其他工具共用一份 Electron。

## 0.9.1（2026-10-28）

- 新图标：取景框里的黄色便签纸。

## 0.9.0（2026-10-22）

第一个发到团队里的版本（独立版；AMO Studio 里带的是同一份）：

- 托盘常驻，只开一份：左键托盘图标显示 / 隐藏，右键是菜单（设置、退出）。
- 全局快捷键默认 Ctrl+Shift+F12；Ctrl+Enter 复制当前页并隐藏，Alt+1…9 换页。
- 设置和页面在 `%APPDATA%\AMO Notes`，工作文件夹可以在设置里换；界面大小是便签自己的设置。
- 和 AMO Studio 带的便签共用同一份数据。
