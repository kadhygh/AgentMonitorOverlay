# AMO 中转（桌面客户端）改动说明

改动先写进「## 下一版」；发布时（`npm run release -- relay` 或 `auto`）它会改成 `## 版本号（日期）`，这一节就是平台上显示的改动说明。

这里只记桌面程序（外壳，`packages/relay-app`）的版本。客户端界面（`packages/relay-ui`）照旧由中转服务下发、自己更新，不走这里的版本号。

## 下一版

## 0.9.8（2026-11-04）

- 配合 AMO 平台更快地知道中转开着还是关了，平台卡片上的「关闭」不用再等好几秒：运行时在 `%APPDATA%\AMO Relay` 里记下自己的进程号，退出时删掉。

## 0.9.7（2026-11-04）

- 用 AMO 平台的账号登录时，给 AI 用的中转身份（`%APPDATA%\AMO Relay\settings.json`）不再写明文的登录密钥，只记「用平台的账号」，用到时从平台加密保存的账号里读。以前存下的明文身份，打开中转时会自动换成这种写法。AI 和命令行里的 `amo-relay` 照常能用；在平台里退出登录后，它们也跟着退出。

## 0.9.6（2026-11-03）

- 程序包瘦身：桌面程序的文件夹从 3871 个文件减到 1808 个，第一次安装和每次装新版要建的文件少了一半多。去掉的是重复的一份内部模块、类型声明、source map，以及第三方包里的说明文档、测试和示例；各包的许可证照留。用起来没有变化。

## 0.9.5（2026-11-02）

- 从 AMO 平台装的中转，任务栏上显示的是 Electron 的图标，现在改回中转自己的图标。

## 0.9.4（2026-10-29）

- 有等你处理的会话或没读的聊天时，任务栏图标会闪，并带一个数字角标；托盘图标也会带着数字闪。看过窗口就不闪了，数字清零后角标消失。
- 从 AMO 平台打开时没有自己的托盘图标，这时平台的托盘图标会换成中转的图标来闪，也带数字。

## 0.9.3（2026-10-29）

- 单独打开中转时，托盘右键菜单换成和便签一样的样式。从平台打开时照旧没有自己的托盘图标。

## 0.9.2（2026-10-29）

- 从 AMO 平台打开时，中转不再在托盘里放自己的图标：打开、退出都在平台的托盘菜单里。单独打开时照旧有自己的托盘。

## 0.9.1（2026-10-29）

- 用 AMO 平台的账号登录：平台里登录了，打开中转就直接连上，不再要你另外登录；平台里换账号、退出登录，中转也跟着变。平台里没登录时，中转会提示去平台登录。
- 退出登录、换账号都在 AMO 平台的「账号」里做，中转的设置里不再有「退出登录」。

## 0.9.0（2026-10-28）

第一个从 AMO 平台发布的版本（之前的 0.1.0 只在下载页的 zip 里）：

- 在 AMO 平台的「工具」里安装、打开、更新、回滚、卸载，和别的工具一样；从平台打开时，服务器地址已经填好（平台登录的那个）。
- 平台装的中转不再自己「更新桌面程序」：桌面程序在平台里更新，界面照旧由服务器下发、自己更新。服务器上的界面需要更新的桌面程序时，提示「在 AMO 平台的「工具」里更新 AMO 中转」。
- 接入 AI 的配置和 `amo-relay.cmd` 指向平台的 `current` 文件夹，平台换版本、清掉旧版本后照样能用。
- 账号、密码、聊天记录和接入信息照旧在 `%APPDATA%\AMO Relay`，从下载页 zip 换到平台装的不用重新登录。
