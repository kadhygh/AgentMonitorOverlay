# 第 1 章 · 5 分钟走通第一件事 {#ch1}

从打开平台，到让 AI 改完一处代码、你看过改动、把任务标成完成。下面的例子是：在项目 `MyGame` 里，让 AI 给导入器的网络请求加上失败重试。

## 开始之前 {#ch1-prep}

只有第一次要做：

1. **AMO 平台**：平台是一个文件夹，里面有 `AMO Platform.exe`。把整个文件夹放在本机硬盘上能写的位置（比如 `D:\TOOLS`），双击 `AMO Platform.exe` 打开。工具会装在这个文件夹里，不用管理员权限。
2. **账号**：用团队服务器（AMO 中转）的账号登录。还没有账号，在登录页点 [[没有账号？注册一个]]。
3. **模型的登录**：Studio 用的是你本机 Claude Code 和 Codex 的登录，和终端里是同一个账号、同一份额度。平台的 [[环境]] 页能查它们装没装、是不是最新；没装的给 [[去下载]]。Claude Code 没登录过的话，在终端运行一次 `claude` 登录。

## 第 1 步 · 登录平台，装上 Studio {#ch1-install}

::scene platform-install

- 登录页的 [[服务器地址]] 填团队服务器，比如 `172.16.8.85:47120`；登录过的服务器会列在 [[最近用过：]] 后面，点一下就填好。
- 登录后左边是 [[工具]]、[[环境]]、[[目录]]、[[设置]] 四页，左下角是你的账号。
- 工具卡片上的状态：[[没装]]、[[已是最新]]、[[有新版]]。有新版时按钮是 [[更新到]] 加版本号；更新不会关掉正在用的工具，下次打开就是新版。
- 平台默认用稳定通道；想先拿到刚发布的版本，在 [[设置]] → [[更新通道]] 里选 [[测试]]。

## 第 2 步 · 设 Studio 数据目录，打开 Studio {#ch1-open}

::scene platform-open

- Studio 的会话、项目、设置都存在**数据目录**里，升级 Studio 不会碰它。第一次从平台打开 Studio 之前一定要设，没设时点 [[打开]] 会被带到 [[目录]] 页。
- 以前从源码启动过 Studio 的，选原来的 `studio\.data`，就能接着用原来的会话和项目。
- 同一时间只开一份 Studio。

## 第 3 步 · 登记项目，新建任务 {#ch1-task}

::scene studio-first-task

- 新的 Studio 看板是空的，四列 [[待办]]、[[进行中]]、[[待审阅]]、[[完成]] 都写着 [[空]]。第一步是在左栏登记项目：[[+ 添加项目]]（已经有项目时，点 [[项目]] 那一行右边的 `+`）。
- 选好文件夹就登记了；也可以在 [[或输入路径]] 里粘贴路径，再点 [[登记]]。
- 点右上角的 [[+ 新任务]]，主区域变成一页草稿（[[要推进什么？]]）。从某个项目里点的，项目已经选好。专题可以 [[不选]]。
- 写下第一句话，选模型，点 [[开始]]（或直接回车）就开出第一段会话。只想先记下这件事、不马上开始，点 [[放进待办]]（`Ctrl+Enter`）。
- 权限先用默认的：Claude 是 [[每次询问]]，Codex 是 [[逐条询问]]，每条命令都会先问你。熟了以后可以换成 [[帮我审批]]：Claude 由 Claude Code 的分类器按风险替你批准或拒绝，拿不准时再问你；Codex 在沙箱里跑，要越出沙箱时交给 Codex 的审查 agent 决定。
- 在任何页面按 `Ctrl+N` 会弹出一行的快速启动条，写一句话就能开始。

## 第 4 步 · 在对话里批准命令 {#ch1-approve}

::scene studio-approve

- AI 要跑命令时，对话里出现 [[请求执行命令]] 卡片，写着 [[等待你的确认]]；顶栏同时亮起 [[需要你]] 和数量。看清命令再点 [[批准]]；不想让它跑就点 [[拒绝]]。
- 处理过的请求在对话里缩成一行（[[已批准]] 或 [[已拒绝]] 加上命令）。
- AI 还在写的时候，输入框也能用：Claude 和 Codex 会把你的话插进这一轮（按钮写 [[插话]]），DeepSeek（DSH）会等这一轮做完再发（按钮写 [[排队]]）。
- 打开了 [[Focus]] 的话，要批准的命令也会出现在桌面角落的 Focus 小窗里，不用切回主窗口就能批。
- 会话停下几秒后，任务卡片自己从 [[进行中]] 移到 [[待审阅]]；你再发消息，它又回到 [[进行中]]。AI 自己不会挪卡片。

## 第 5 步 · 看改动，标完成 {#ch1-review}

::scene studio-review

- [[Review]] 打开的是这个项目的 Git Review 窗口（只有 git 项目才有这个按钮）。上面可以切 [[工作区改动]]、[[本分支全部]]、[[已暂存]]，[[只看改动]] 或 [[完整文件]]，[[单栏]] 或 [[左右对照]]。
- 鼠标移到某一行，点行号旁边的 `+` 写批注；写完点 [[保存]]（或 `Ctrl+Enter`）。所有批注都是草稿，攒好了一起复制。
- [[复制注释]] 把批注（带着文件、行号和那一行的内容）复制下来；[[复制并关闭]] 复制完顺便关掉窗口。回到对话粘贴、回车，AI 就照着改。
- 标完成：点任务标题下面那行最前面的状态字，选 [[完成]]（菜单开着时按 `1`–`4` 也行）；或者在看板上把卡片拖到 [[完成]] 列。完成的多了，[[完成]] 列标题旁的 [[全部归档]] 一次收起来，在 [[已归档]] 里还能打开、恢复。

## 卡住了？ {#ch1-faq}

| 现象 | 怎么办 |
|---|---|
| 平台里点 Studio 的 [[打开]]，跳到了 [[目录]] 页 | 还没设 Studio 数据目录：点 [[选择文件夹…]] 选一个，再回 [[工具]] 页点 [[打开]] |
| 新任务页的 [[开始]] 是灰的 | 还没选模型。点输入框下面的模型，或者 [[全部型号]] 里挑一个 |
| 模型开不起来、选不到 Claude 或 Codex | 在平台的 [[环境]] 页看它们装没装、是不是太旧；在 Studio 左下角 [[设置]] → [[模型]] 看它的账号是不是 [[已登录]] |
| 任务页没有 [[Review]] 按钮 | 项目文件夹不是 git 仓库，Git Review 用不了 |
| 关了窗口，会话还在跑吗 | 在跑。× 只收起窗口。从托盘再打开：Studio 自己的托盘图标单击就行；从平台打开的 Studio 在平台托盘的右键菜单里点 [[打开 Studio]] |
