# 第 7 章 · 便签：边看边记 {#ch7}

看 AI 的改动、读它的报告时，想到的点先记下来，攒一页一起贴回对话。AMO 便签是一个单独的小工具：托盘常驻，按快捷键随时呼出；Studio 打开时会顺带启动它，不开 Studio 也能单独用。

## 呼出、记、贴回去 {#ch7-use}

- 默认快捷键 `Ctrl+Shift+F12`，在哪个程序里都能按，再按一次或按 `Esc` 隐藏。快捷键在便签的设置里改（[[快捷键]]）；输入法占了某个组合键时，换一个就行。
- 一共几页，`Alt+1…9` 换页，可以一页记一件事。
- 记好了按 `Ctrl+Enter`：复制这一页并隐藏。回到对话粘贴、回车，AI 照着改。
- 便签的内容存在工作文件夹里，换电脑、重装都不会丢；在设置里 [[更换工作文件夹]]。

## 和审阅一起用 {#ch7-review}

- 一边在 Reviewer 里看改动，一边把「要改的地方」记在便签里；看完一次复制，比来回切窗口一条条发快。
- 有具体某一行的意见，用 Reviewer 的行内批注（第 4 章）；整体的想法、跨文件的要求，记在便签里。
