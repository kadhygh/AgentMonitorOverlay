# 第 6 章 · 专题、任务、会话和画布 {#ch6}

一件大事常常跨几个项目，要好几个任务一起推进。AMO 在常见的「项目 › 会话」上多包了两层：会话包进任务，任务归进专题；专题的画布把这些任务和它们之间的关系摆在一张图上。

## 和「项目 › 会话」比 {#ch6-compare}

| | 常规的 IDE / CLI | AMO Studio |
|---|---|---|
| 怎么开始 | 先选项目，在项目下开会话 | [[+ 新任务]]：写一句话，项目、专题、模型在下面选 |
| 一件事的几段会话 | 混在项目的会话列表里 | 都在这个任务里：主会话、分支、子会话 |
| 跨几个项目的一件大事 | 没有地方放 | 专题：几个项目的任务归在一起，有自己的画布 |
| 谁等谁、做到哪了 | 靠人记 | 专题画布上的卡片和依赖线 |

## 任务里的几段会话：强模型带弱模型 {#ch6-sub}

- 任务页左边是这个任务的会话列表。[[新会话]] 开一段新的；[[分支]] 从某一处分出去，比如换个模型再试一遍，两边结果对照着看。
- **子会话**：让强一些的模型定方案、审结果，把重复的细活交给便宜的模型做。在输入框里打 `@`，选 [[开子会话…]]，挑子会话用的模型和强度，再写清要它做什么；主模型会开出子会话，子会话每做完一轮，结果自动回到主会话，主模型接着审。
- 主模型自己也会这样分活。哪个模型适合当子会话、适合做什么，在 [[设置]] → [[子会话]] 里给每个模型写一段说明，主模型挑的时候会读。

## 专题：一件大事，跨几个项目 {#ch6-topic}

- 建专题：左栏 [[专题]] 那一行右边的 `+`（还没有专题时点 [[+ 新专题]]）。每个专题有一张自己的画布。
- 例子：一个 git 仓库开三个 worktree，各在一个分支上改。worktree 用 git 自己建（比如 `git worktree add ../MyGame-drop drop`；Studio 不建分支、不合并），再把三个文件夹各登记成一个项目：`MyGame`、`MyGame-drop`、`MyGame-ui`。
- 专题「3.2 版本」下开三个任务：掉落表改版在 `MyGame-drop` 里，背包界面在 `MyGame-ui` 里，合并验证在 `MyGame` 里。几条线各改各的，互不干扰、分别验证，最后在主目录合到一起。
- 新任务页选了专题，项目那一栏会标出这个专题常用的项目（[[专题常用]]）；勾上 [[显示在画布上]]，任务建好就放上专题画布。

## 设一个主控 {#ch6-lead}

- 新任务页勾 [[设为主控]]（[[协调这个专题的任务]]）。之后在任务页也能改；不要了在 `⋯` 里点 [[取消主控]]。
- 主控负责拆任务、排画布、写专题文档；具体的活由各个任务自己的会话做。
- 主控想拆任务时会提一个 [[拆任务提案]]：画布顶上出现一条，点 [[查看]]。每个任务都能去掉，或者改名字、项目、模型、说明和第一句话；然后 [[立刻开跑]] 或 [[放进待办]]，建好的任务会放上画布、连好依赖。不要就点 [[不采用…]]，可以写一句为什么，它会看到。

## 让主控用画布整理任务 {#ch6-ask}

::scene canvas-lead

- 主控不会自己去动画布，要你开口。直接说要怎么排，比如：「把 3.2 的任务按 worktree 分组排到画布上，标出谁等谁」「把还没开始的放进一个组」「合并验证要等前面两个做完」。
- 它用这几样改画布：[[画布建组]]（组可以绑一个项目）、[[画布归组]]（把专题里的任务放进组，没上画布的也会放上去）、[[画布连依赖]]（谁要等谁做完），还能给卡片标颜色。除了标颜色，每次改画布都先问你，点 [[批准]] 才改。
- 它读画布只读结构，不读坐标：有哪些组、组里有哪些任务、谁依赖谁、还有哪些任务没摆上去。放进组的卡片摆在哪由 Studio 定，之后你可以自己挪。
- 画布点 [[小窗]] 可以单独开成一个小窗，总在别的窗口上面，一边跟主控说、一边看它排。

## 自己动手摆 {#ch6-manual}

::scene canvas-manual

- 工具栏：[[+ 在专题里新建任务]]、[[+ 分组]]、[[引用任务]]（把别的专题的任务放过来参考）、[[+ 便签]]、[[小窗]]；右边的 [[侧栏]] 里有 [[整体待办]] 等几页。
- 画布底下一行写着怎么操作：拖空白处移动视角、滚轮缩放、从卡片边上的圆点拖出连线（就是依赖）、单击看详情、右键看更多操作（比如标颜色）、双击打开任务。
- 详情框里有 [[打开任务]]、[[从画布上拿掉（任务不变）]]，下面是它的 [[前置任务]]，也能在这里加。

## 看推进 {#ch6-watch}

- 卡片上是任务的状态和项目，跟着任务实时变；依赖线标出谁在等谁。
- AI 也会在卡片上写说明、提问题，左栏的专题旁边会标出有几个问题等你答。点开问题就能回答，[[发送回答]] 后它接着做；想看上下文点 [[去对话里看]]。
