# 第 9 章 · 远程：换台设备接着用（测试中） {#ch9}

在台式机上跑着的任务，拿笔记本或手机接着看、接着发话、接着批命令。

> **! 先看风险。** 远程会话还在原来那台电脑上跑：命令以那台电脑上**你的用户身份**运行，用的是那台电脑的模型账号。所以：
>
> - **只在局域网里用**，不要把它开到外网；
> - **只配对你自己的设备**（你的电脑、你的手机）；
> - 不认识的配对请求、不是你发起的任务请求，一律拒绝；
> - 用完了把授权收回。

## 开始之前 {#ch9-prep}

- 两台电脑都装好 AMO 平台，用**同一个账号**登录。Studio 的远程用的是平台存的登录，没登录时会提示 [[在 AMO 平台里登录]]。
- 两台电脑在同一个局域网里，能连上团队服务器。

## 配对：只配对你自己的电脑 {#ch9-pair}

- 在笔记本上点顶栏的 [[远程]] → [[+ 配对设备]]：列出同一个账号、现在在线的设备。选台式机，点 [[发起配对]]。
- 台式机上 [[远程]] 里出现 [[收到的配对请求]]，确认是你自己的笔记本，点允许。之后两边的 [[已配对的设备]] 里都有对方。
- 不再用的设备点 [[解除配对]]，授权给它的任务也一并收回。

## 授权一个任务，换台设备接着用 {#ch9-grant}

- 在台式机上打开那个任务，`⋯` 里点 [[授权给…]]，选笔记本。笔记本的看板上就会出现这个任务，标着「远程」和在哪台电脑上运行。
- 在笔记本上可以发话、批准命令、看回复，和在台式机上一样；但会话、命令都还在台式机上跑。
- 有任务授权给在线的设备时，台式机不会自动睡眠（屏幕照常会关），免得那边用到一半断掉。
- 也可以反过来：在笔记本的新任务页选 [[在别的设备上]]，把任务直接建在台式机上跑。台式机能接哪些项目、哪些模型，在台式机的 [[远程设置]] 里的 [[远端允许的项目]]、[[远端允许的模型]] 里勾；一个项目都不勾，别的设备就不能在这台电脑上建任务。

## 在手机上用（测试中） {#ch9-phone}

- AMO Studio 有 Android 版（测试中），团队服务器的首页可以下载。手机上填团队服务器的地址，用**同一个账号**登录，从在线的设备里选你的电脑申请配对，到电脑上的 [[远程]] 里允许。
- 之后手机上能看这台电脑授权给它的任务，也能直接在电脑上建任务；发话、批准命令、回答提问、打开回复里的文件都行。
- 和笔记本一样：会话、模型调用和命令都在电脑上跑，手机只是遥控。手机切到后台不会停电脑上的任务。

## 安全：先等你同意，随时收回 {#ch9-safety}

- [[远程设置]] 里的「安全」管别的设备在这台电脑上建的任务：[[同账号的设备]] 默认 [[直接开跑]]，[[别的账号的设备]] 默认 [[先等我确认]]。
- 「先等我确认」：任务先不建、不跑，这台电脑的 Focus 和 [[远程]] 里出现一条请求，看过项目、模型和第一句话再点 [[同意并开始]]。不认识的就拒绝。
- 别的账号的设备建的任务会直接用这台电脑的模型账号跑；Claude、ChatGPT 的个人订阅不能给别人用。
- 授权出去的任务在 [[远程]] 的 [[授权给别的设备的]] 里列着，点 [[收回]]：那边只留下已经同步的记录（只读），不能再操作。
