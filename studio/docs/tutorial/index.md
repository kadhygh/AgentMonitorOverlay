# AMO 使用教程

这份教程按「要做的事」来讲，不按功能列表。每一章先说这件事在 AMO 里怎么做，再放一段**会动的演示**：演示里画的是简化过的界面，只留这一步用到的部分，按钮的名字和真实界面一致。

演示怎么看：滚到演示那里它会自己播；随时可以 [[~暂停]]、[[~上一步]]、[[~下一步]]，或者点字幕下面的小圆点跳到某一步。系统设了「减少动态效果」时不自动播，用 [[~下一步]] 一步步看。

软件里的按钮、菜单、页面名写成 [[~这样]]，照着找就行。

> 这是第一版，只有第 0、1 章，先用来定风格和讲解的细致程度。后面的章节（从 Claude Code / Codex 过来、同时推进几件事、审阅 AI 的产出、换个思路、画布、便签、中转、远程）定了再写。
