# 第 4 章 · 审阅 AI 的产出 {#ch4}

AI 改完代码、写完报告，要你看。AMO Reviewer 让你直接看到关键的那几行，在原处写批注，再一键复制回对话。它是一个单独的工具：Studio 里带着一份，也能从平台单独装 [[AMO Reviewer]]，不开 Studio 也能看任何文件夹的改动和文件。

## AI 直接带你到关键几行 {#ch4-pack}

- AI 改完以后，可以直接把要你看的东西打开给你：几个文件放进一个 [[查看包]]，每个文件标出 [[重点]] 的那几行，旁边写一句为什么要看；表格、配置这类没法逐行看的，给的是 [[改动预览]]。
- 这一步 AI 用的是 AMO 的 `view_open`（一个查看包）和 `review_open`（一个文件的某几行，或者 Git 改动）。你也可以直接跟它说：「改完把关键的地方放进查看包给我看」。
- 查看包会留着，之后还能再打开；同一个任务里接连打开的会合在一起。

## 行内批注，一键复制回对话 {#ch4-comment}

- 在 Git Review 或查看包里，鼠标移到某一行，点行号旁边的 `+` 写批注，写完点 [[保存]]（或 `Ctrl+Enter`）。批注先存成草稿，可以攒好几条。
- [[复制注释]] 把所有批注连同文件、行号和那一行的内容一起复制下来；[[复制并关闭]] 复制完顺便关掉窗口。回到对话粘贴、回车，AI 就知道你指的是哪一行。
- Git Review 的用法（[[工作区改动]]、单栏或左右对照、标完成）见第 1 章第 5 步。

## HTML 报告、Markdown 也能批注 {#ch4-viewer}

- 对话里点文件的链接，会在 [[查看器]] 里打开：HTML 和 Markdown 渲染成页面看。查看器是一个独立的窗口，下一次点链接会接着用它；想留着当前这份，点 [[固定]]。
- 选中一段文字可以写批注；HTML 报告里在图表、图片这类选不中文字的地方，右键 [[在这里批注]]，批注就钉在那个位置。
- 批注同样是 [[复制注释]] 复制回对话，带着位置，AI 知道你说的是哪一处。
- 看到值得留着的段落，点 [[~加到书签]] 放进这个专题的书签里（只在 AMO Studio 里有）。
