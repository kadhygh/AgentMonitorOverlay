# 第 3 章 · 同时推进几件事 {#ch3}

几件事分给不同的 AI 同时跑，你接着干自己的；只在要你批准、回答或者看结果的时候过去一下。

## 看板：每件事一张卡 {#ch3-board}

- 每件事是一个任务，在看板上是一张卡片。四列：[[待办]]（还没开始）、[[进行中]]（有会话在跑）、[[待审阅]]（会话停了，轮到你看）、[[完成]]。卡片在 [[进行中]] 和 [[待审阅]] 之间自己挪，不用你拖。
- 开一个任务就是一句话加一个模型：[[+ 新任务]]，写下第一句话，在下面点一个模型，[[开始]]。`Alt 1-4` 换常用模型。
- 模型可以混着用：Claude（本机 Claude Code 的登录）、Codex（本机 Codex 的登录）、DeepSeek，还有你在设置里加的第三方渠道（[[添加第三方渠道]]：填网址和 API Key）。几个任务各用各的，同时跑。

## 额度和余额，一眼看到 {#ch3-usage}

- 左栏最下面那一行写着 [[Host 运行中]]，后面是各个订阅用得最多的那一档（比如 `Claude 18%`）和第三方渠道的余额。
- 点它展开：每个账号的几个时间窗各剩多少、多久后重置；展开着的时候每 5 分钟读一次，也可以点 [[刷新]]。
- 显示哪些账号，在 [[设置]] → [[额度]] 里选。第三方渠道的余额要先在渠道设置的 [[余额查询]] 里选好查询方式。

## Focus：需要你的时候才喊你 {#ch3-focus}

- 顶栏的 [[Focus]] 打开一个悬浮窗：放在桌面角落，总在别的窗口上面，你写文档、看表的时候也看得见。
- 它只列需要你的会话：要 [[批准]] 的、要回答的、做完了等你看的（[[完成待审核]]）。每行最前面是状态字，比如 `! 批准`、`◐ 运行`、`✓ 完成`，不光靠颜色。
- 点一行展开，看它最新写了什么。要批准的，直接点 [[批准]]，不用切回主窗口；做完的可以点 [[我知道了]]，算你看过了，从 Focus 里移走。

## 置顶：一直盯着一个任务 {#ch3-pin}

- 想一直看着某个任务、不等它喊你：鼠标移到 Focus 里它那一行，右边出一个图钉，点一下就 [[置顶]]。
- 置顶的任务放在 Focus 最上面一组，一句话写着它现在在做什么；要你批准或回答时，就地展开让你处理。它做完了也不会从 Focus 里走，直到你再点一下图钉取消置顶。
- 置顶只在这台电脑的 Focus 里，不改任务本身。

## 从 Focus 回到对话开头 {#ch3-jump}

- Focus 里展开一行，点 [[在工作台打开]]，主窗口就跳到那个任务、那段会话，对话停在最后。
- 这一轮回复很长、开头已经滚出去了的时候，对话底部会出一个提示：按 `↑` [[回到本轮回复开始]]。按 `↑` 或点它，就回到这一轮回复的开头，从头看起；按别的键、点别处或滚动，提示就收起来。
