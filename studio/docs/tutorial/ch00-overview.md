# 第 0 章 · 一张图看懂 AMO {#ch0}

AMO 是一组给「有 AI 参与的项目」用的 Windows 桌面工具。你先装 **AMO 平台**，再从平台装其他工具；每天主要用的是 **AMO Studio**：在那里把事情交给 AI（Claude、Codex、DeepSeek），看它干活，批准它要跑的命令，审它改的代码。

## 工具和几个词的关系 {#ch0-map}

点图上的方块看说明。

::concept-map

只记四个词就能开始用 Studio：

- **项目**：电脑上的一个文件夹，通常是一个 git 仓库。AI 的命令在这个文件夹里跑，改的也是这里的文件。
- **任务**：一件要推进的事，在看板上是一张卡片。一个任务属于一个项目；新建时不选项目，它就在「公共目录」里跑。
- **会话**：和某个模型的一段对话，相当于在终端里开一次 `claude` 或 `codex`。一个任务下面可以有几段会话：换个模型再试、从某处分支出去、让 AI 自己开子会话。
- **专题**：比任务高一层，把相关的任务放在一起，可以跨几个项目。每个专题有一张自己的画布。只做一件小事时可以不用专题。

用过 Claude Code / Codex 的话可以这样想：终端里的一次对话 = Studio 里的一个**会话**；Studio 在外面多包了**任务**和**专题**两层，好让你同时推进几件事、回头还找得到。

## 窗口一览 {#ch0-windows}

Studio 不只一个窗口。下表是每个窗口干什么、从哪打开：

| 窗口 | 是什么 | 从哪打开 |
|---|---|---|
| 主窗口 | 看板、任务页、对话、画布都在这里。点右上角 × 只是收起窗口，Studio 和会话留在托盘里继续跑；真要退出用托盘右键菜单的 [[完全退出]]（从平台打开的 Studio 在平台的托盘菜单里，叫 [[完全退出 Studio]]） | 平台的 [[工具]] 页 → AMO Studio → [[打开]] |
| Focus | 桌面角落的悬浮小窗，只列需要你处理的会话：要批准的命令、要回答的问题、做完待看的回复。要批准的可以直接在 Focus 里批 | 主窗口顶栏的 [[Focus]]，点一下打开，再点一下关上 |
| 便签 | 单独的小程序，托盘常驻，随手记 | 顶栏的 [[便签]]，或者它的全局快捷键（默认 `Ctrl+Shift+F12`，在便签的设置里改） |
| 书签 | 按专题收着的文件和对话片段，可以拖进对话 | 顶栏的 [[书签]]（`Ctrl+Shift+M`），或任务页右上角的 [[书签]] |
| 画布小窗 | 一张专题画布单独放在一个置顶的小窗里，做别的事时也能看到进度和问题 | 看板旁边的 [[画布]] 页签 → 画布上方的 [[小窗]] |
| 查看器 | 单独的窗口，看对话里提到的文件：HTML 和 Markdown 渲染出来看，代码按行看，都能写批注 | 在对话里单击文件名；或右键文件名 → [[在查看器中打开]] |
| Git Review | 看一个项目还没提交的改动，按行写批注 | 任务页右上角的 [[Review]]（只有 git 项目才有）；或在左栏右键项目 → [[Git Review]] |
| 远程 | 在你自己的另一台电脑上接着用这台电脑的会话：配对设备、授权任务、远程设置 | 顶栏的 [[远程]]。只推荐在局域网里、在你自己的几台设备之间用，第 9 章会先讲风险 |
