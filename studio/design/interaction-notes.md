# 交互细节

这里记录已经确认的交互决定，loop 每一轮都会读。用户可以随时在末尾的"待补充"里追加内容，loop 会把它们转成任务。

视觉与交互以设计预览为准：https://claude.ai/artifact/LyWa7NybnLR3Ro84wdGPgv，本地副本在 `design/prototype/`。原型里的模拟数据（Project Mining、矿车寻路等）只用于演示，不能写进产品。

## 总原则：轻便

- 一个状态只显示一次：一个状态点加一个状态词，不同时出现重复的标签。
- 卡片本身就是入口，卡片上不放操作按钮。
- **任务状态和会话状态分开**：
  - 任务状态就是看板的列（待办、进行中、待审阅、完成），由人手动调整；
  - 会话状态（运行中、待批准、待审阅、空闲、已完成）自动更新；
  - agent 不会自动把卡片移到别的列。
- Focus 悬浮窗只回答一个问题："现在有什么要我处理"。可以展开看最新一段内容，可以就地批准；其他操作都跳回工作台。

## 视觉

- 深色主题：
  - 背景 `#111316`；
  - 面板 `#181B1F`，边框 `#2B3036`；
  - 正文 `#E6E8EB`，次要文字 `#A0A8B2`。
- 强调色：
  - 主操作 `#7FB2FF`（按钮上的文字用 `#0B1626`）；
  - 需要处理 `#F2B544`；
  - 运行中 `#5CC98A`。
- 字体：IBM Plex Sans 和 Noto Sans SC 用于界面，JetBrains Mono 用于代码。
- 无障碍：
  - 文字对比度至少 4.5:1；
  - 按钮使用真实的 `<button>`；
  - 只有图标的按钮要加 `aria-label`。

## 范围与工作区

- 左栏的"范围"包含：全部、跨工作区、各个工作区。
- 任务属于一个工作区，或者属于"跨工作区"。跨工作区任务里的每个会话，各自指定所在的工作区。

## 新建任务

- 点"+ 新任务"，打开一个空白的任务页（DSH 式），不用弹窗或表单。
- 顶部只有"← 看板"和"新任务"。
- 中间从上到下：
  1. "要推进什么？"
  2. **标题编辑区**：居中的输入框，可以留空，留空时按第一句话自动命名。
  3. 范围选择：默认选中当前的工作区；在"全部"视图下，默认上次用的工作区；包含"跨工作区"选项。
  4. 一行范围说明。
- 底部是对话输入框，配模型选择；选了跨工作区时，还要选"首个会话在哪个工作区"。点"开始"，同时创建任务和第一个会话。

## 任务页

- 三栏：会话列表 | 对话 | 批注与草稿。
- **会话列表**：
  - 一个任务有多个独立会话，每个会话有自己的模型；
  - 分支和子 agent 缩进挂在所属会话下面；
  - 每一行显示状态点、标题、类型、模型，跨工作区任务还显示所在工作区；
  - 底部有新会话的模型选择（跨工作区任务还要选工作区）和"+ 新会话"。
- **归档**：
  - 当前会话顶部有"归档"按钮；
  - 归档时，它下面的分支和子 agent 一起归档；
  - 归档后收进列表底部不显眼的"▸ 已归档 n"，展开后可以查看（只读）或恢复。
- **对话顶部**：会话标题、模型（跨工作区时加上工作区）、写入状态、"在终端打开"、"归档"。
- **写入状态**有四种：仅工作台、终端已接入（共享）、已交给终端（只读）、已归档（只读）。

## 对话

- 回复以 markdown 显示，流式输出时显示"生成中…"。
- 工具调用显示为折叠卡片，点击展开详情。
- 审批卡片带"批准"和"拒绝"，处理后显示结果。
- 子 agent 显示为一条摘要，带"查看"，点击跳到子会话。
- 回复生成中时，发送按钮变为"插话"，旁边出现"打断"。
- **在终端打开**：
  - Codex：显示"终端已接入 · 共享"，工作台仍然可以输入。
  - Claude：工作台变为只读，并显示提示条，说明原因（避免两边同时写入丢失内容），提示条上有"立即收回"。

## 批注

- 每一段旁边不放批注按钮。
- 选中回复里的文字后右键，菜单里有"添加批注"、"引用到输入框"、"复制"。
- "添加批注"后，右栏出现一张批注卡：上面是引用的原文，下面是输入框。保存后，原文所在的段落高亮。
- 批注可以积累多条，再一起"汇总发回会话"，以一条用户消息的形式发出。
- **草稿区**放在右栏底部。待确认：草稿区是全局的，还是跟着任务走。在用户确认之前，先做成全局的。

## 画布

- **无限画布**：
  - 拖动空白处平移；
  - 滚轮或按钮缩放；
  - "复位"回到初始视图。
- **自由分组**：
  - 由人新建；
  - 拖标题栏移动，组内的卡片和便签一起移动；
  - 拖右下角调整大小；
  - 可以改名、选择绑定一个工作区；
  - 删除分组时保留卡片。
- **卡片归属**：卡片拖进哪个组，就自动归入哪个组；拖到组外，就变成未分组。
- **依赖**：在侧栏为选中的任务添加前置任务，箭头从前置任务指向依赖它的任务。
- **便签**：可以拖动，可以放进分组。
- **侧栏**有三个标签页：
  - 整体待办；
  - 详情（任务详情或分组设置）；
  - agent 视角：画布的结构化大纲和 JSON，也就是 `canvas.read` 的返回内容。
- 画布按结构化数据存储，坐标只是表现层；agent 不需要读坐标，就能理解分组、任务和依赖。
