## 已确定的做法

| 项目 | 做法 | 说明 |
|---|---|---|
| markdown 渲染 | 继续用自研的安全渲染器（React 文本节点，不注入 HTML），补表格、嵌套列表、代码块语言标签与复制 | 不引入 HTML 型 markdown 库，避免 XSS；渲染时给每个块记下它在源文本里的区间，供批注定位 |
| 批注锚点 | 存 `quote` 加前后各 24 个字的上下文和源文本区间；定位时先按区间，区间对不上再按"上下文 + 原文"查找 | 回复是只读的，区间通常稳定；上下文用于兜底 |
| 右键菜单 | 在对话区捕获 `contextmenu`，有选中文字且选区在某条回复内时显示自定义菜单 | 不用 Electron 原生菜单，便于 e2e 驱动 |
| 草稿区 | 全局一份（interaction-notes 的默认），存在 Host 的 kv 表里 | 用户以后若要按任务分开，再加一个作用域字段 |
| 外部链接 | 回复中的 http/https 链接通过 preload 交给系统浏览器打开，其他协议不处理 | 主进程只放行 http/https |
| 额度 | 全阶段用 mock 模型，不消耗真实额度 | |
