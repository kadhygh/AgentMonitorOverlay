# Focus 收起成悬浮块，自动展开

> 状态：做完（2026-11-10）。外观原型 `focus-mini-prototype.html`（同目录，没进 git）。

## 用户定的（2026-11-10）

- Focus「收起成一行」改成：缩成一个图标带底部块的悬浮小块。外观用方案 A：上面 AMO 图标，下面一条只显示最要紧的一个数——有事琥珀色「! N」（新的没看过时轻轻呼吸），完成待看绿底「✓ N」，在跑浅绿「▶ N」，没事灰「—」。
- Focus 设置里加「自动展开」：
  - 不勾（默认）：默认收起，有互动时自动展开。
  - 勾上：鼠标移到悬浮块上自动展开，移走自动收起；有互动时也自动展开。
- 其余按建议：
  - 有互动自动展开后，那件事处理完（需要你的事变成 0）就收回；鼠标还在 Focus 上就等移开再收。
  - 点悬浮块展开并保持（勾不勾都一样），⌄ 收回。
  - 机器人站在悬浮块上方，气泡照旧。
  - 「有互动」只算需要你处理的事（审批、提问、决定、提案、中转、配对……），完成待看不自己展开，只在悬浮块上显示 ✓ N。

## 做法

- `ui/src/focus/FocusApp.tsx`：`collapsed`（记住，`amo.focusCollapsed`，默认收起）、`autoExpand`（`amo.focusAutoExpand`）；展开 = 没收起 || 有事展开 || 悬停展开 || 移动 / 调大小中。有事展开看「需要你」的 key 有没有新的（`attention.ts` 的 `opensFocus`），悬浮块的底条是 `miniStatus`。
- 悬停：鼠标进悬浮块（120 ms 后）展开；离开 Focus（窗口形状就是 Focus 画的部分，离开形状就是离开窗口）350 ms 后收起。
- 窗口形状把 `.focus-mini` 算进去（`windowShape.ts`），收起时窗口只拦悬浮块那一小块的点击。
- e2e 默认让 Focus 展开（`launchStudio` 的 `focusCollapsed`），悬浮块自己的用例在 `e2e/studio/focus.spec.ts`。
