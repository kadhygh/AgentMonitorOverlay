### 用户的决定（2026-10-14 晚）

- **第 8 条：批注跟文件走，发送时选会话。** 查看器文件模式也能按行加「+」批注，和 Review 共用同一套批注和底部发送栏。批注挂在「文件 + 行」上，不属于哪个会话；发送栏默认发给最近一次打开这个文件的会话，可以改。同一个文件不管从几个会话打开，看到的都是同一份草稿。
- **E4：归档后弹窗 + 横幅，并且查看 / 创建任务都要记住从哪里来。** 归档整个任务后弹一个提示框，有「返回」和「关闭」：返回 = 回到进入这个任务之前的地方（看板或画布，按任务的入口决定）。任务页常驻「已归档」横幅。另外现在新建任务后点反馈没有回到之前的地方：查看任务和创建任务都要记住之前是从哪里来的。
- 三条线用子 agent 在工作树里并行做。

### 按默认推进的做法（可推翻）

- **查看器批注（S14-A）**：Review 批注的 `range` 加一种 `file`（文件现在的样子，没有 diff，行号就是文件行号）；查看器文件模式的行号旁有「+」，点开就地写批注，和 Review 的批注卡片一样。发送栏和 Review 的一样（选会话、发送全部草稿，汇总格式里写「路径:行号 + 那一行原文 + 说明」）。查看器窗口的地址带上打开它的会话（`session=`），作为发送栏的默认会话；没有来源会话（从标记窗口或 Review 打开）时用这个项目最近活跃的会话。同一个文件的草稿在 Review 的改动模式和查看器的文件模式里都能看到（改动模式里 `file` 草稿按新文件行号对上能显示的行，对不上的列在「其他位置」）。
- **跳到行 / 查找（S14-A）**：Ctrl+G 弹一个小输入框跳到行（文件模式的源码视图，Markdown 渲染时不出现）；Ctrl+F 在查看器（文件和改动两种模式）和 Review 窗口里查找：顶部一条查找栏，Enter / Shift+Enter 下一个 / 上一个，显示「第 i / 共 n 个」，Esc 关闭，可选区分大小写。分块渲染的大文件按数据查找，再滚到命中的行，不依赖浏览器自带查找。
- **便签（S14-B）**：设置 → 便签页加「页数」和「复制时的换行：常规 / 安全换行」（默认常规）。常规 = 去掉行尾空格、去掉末尾空行，换行用 `\r\n`；安全换行 = 把多行合成一行、用空格连接（同旧 AMO `toCliPasteClipboardText`）。便签窗口去掉页数控件，标题处加应用图标。任务页右栏不再放便签入口（纯浏览器里没有便签窗口时，便签入口放到设置的便签页里编辑）。
- **搜索（S14-C）**：「新任务」左边一个搜索框（快捷键 Ctrl+K 聚焦），下拉列出匹配的任务和会话（任务名、会话标题、项目名；已归档的排在后面并标「已归档」），上下键选、回车或点击打开任务 / 会话。
- **置顶（S14-C）**：标题栏 Focus 后面一个「置顶」开关，样式同 Focus 开关；打开后工作台窗口 `alwaysOnTop`，记在 kv 里，下次启动照旧。
- **归档的去向（S14-C）**：进入任务页时记下来源（看板、画布、搜索、Focus 等，新建任务同样记）；任务页的返回按钮回到来源。归档整个任务后，弹出提示框：「已归档任务『…』和它的 N 个会话」，按钮「返回看板 / 返回画布」（按来源）和「关闭」（留在任务页，只读）。不再弹顶部提示。任务页顶部常驻「已归档 · 只读」横幅，带「恢复」。
- **已归档会话（S14-C）**：会话列表底部「已归档」里每行和正常会话行同样的结构（标题、型号、时间），整行变淡并带归档图标和「已归档 · 日期」；悬停出「查看」「恢复」。打开已归档的会话时，对话区顶部一条明显的横幅「已归档 · 只读」带「恢复」，替换原来输入框位置的一行字。
