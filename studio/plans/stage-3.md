# 阶段 3 · 组织层与日常切换

分支：`studio/stage-3`（从 `studio/main` 创建）。目标、验收和关卡见 `ROADMAP.md`：Studio 可以替代旧 AMO 成为日常工具。

依据：ROADMAP 阶段 3；`design/interaction-notes.md` 的"画布"一节和总原则里的 Focus；原型 `design/prototype/Canvas.dc.html`、`Focus.dc.html`；阶段 1～2 的实际结果（Store 已有 `canvas_docs`、`todos` 表，protocol 已有 `CanvasDoc`、`TodoItem`）。

## 已确定的做法

| 项目 | 做法 | 说明 |
|---|---|---|
| 画布存储 | 一份全局画布（`canvas_docs` 里 id 为 `main`），整份文档读写，带版本号做乐观并发 | 结构化数据：分组、任务节点、便签、依赖边；坐标只是表现层 |
| `canvas.read` | protocol 里的纯函数：把画布与任务、工作区拼成"大纲文本 + JSON"，Host 路由和界面"agent 视角"共用 | 阶段 4 的只读 MCP 直接复用 |
| 画布交互 | 自研 SVG/DOM 画布：拖空白处平移、滚轮或按钮缩放、"复位"；不引入画布库 | 交互点少，自研更可控 |
| 依赖 | 在侧栏为选中任务添加前置任务；有环时拒绝 | 箭头从前置任务指向后续任务 |
| 整体待办 | 全局待办列表（`todos` 表），可勾选、删除；"转为任务"和调度在阶段 7 | interaction-notes"后续" |
| Focus | 独立的 Electron 窗口：无边框、透明背景、置顶、默认右下角；只显示需要处理的会话（待批准、待审阅）和运行中计数；可就地批准；其他操作跳回工作台 | 只有卡片区域响应鼠标，透明区域点击穿透 |
| 多显示器与 DPI | 窗口位置按显示器的工作区计算，换显示器或改缩放后重新贴边；用 Electron 的 `screen` 事件 | 自动测试覆盖位置计算；真机观感属于"请你过目" |
| 额度 | 全部用 mock 模型 | DeepSeek 0 次 |

## 任务

### S3-01 画布数据与接口 · done
- 内容：Host 路由 `GET /api/canvas`、`PUT /api/canvas`（带 `version`，版本不符返回 409）；校验（节点引用的任务存在、分组存在、依赖无环、边两端是任务）；任务删除或归档时画布节点保留但标记；`canvas.updated` 事件；protocol 的 `canvasOutline()`（大纲文本与结构化 JSON）。
- 验收：单元测试覆盖校验、环检测、大纲生成；API 测试覆盖版本冲突。

### S3-02 画布视图：平移、缩放、任务卡片 · done
- 依赖：S3-01
- 内容：顶栏"画布"标签可用；无限画布，拖空白处平移，滚轮或按钮缩放，"复位"；任务卡片节点（状态点、状态词，与看板一致），可拖动；新任务默认放在未分组区域。
- 验收：e2e：打开画布、平移缩放、拖动卡片后刷新仍在原处；截图。

### S3-03 自由分组 · todo
- 依赖：S3-02
- 内容：新建分组；拖标题栏移动（组内卡片和便签一起动）；拖右下角调整大小；改名；绑定一个工作区；删除分组时保留卡片；卡片拖进/拖出分组自动归属。
- 验收：e2e 覆盖以上操作。

### S3-04 依赖与便签 · todo
- 依赖：S3-03
- 内容：侧栏"详情"为选中任务添加/移除前置任务，画布画箭头；便签可新建、编辑、拖动、放进分组。
- 验收：e2e；单元测试覆盖拒绝成环。

### S3-05 侧栏：整体待办、详情、agent 视角 · todo
- 依赖：S3-01
- 内容：画布右侧栏三个标签页：整体待办（全局待办，可增删、勾选）、详情（任务或分组）、agent 视角（`canvasOutline()` 的大纲和 JSON）。
- 验收：e2e；截图。

### S3-06 跨工作区任务补全 · todo
- 依赖：无
- 内容：对照 interaction-notes 检查跨工作区任务的完整界面：看板卡片列出涉及的工作区、任务页每个会话显示所在工作区、新会话选工作区、画布里跨工作区任务的显示方式；补齐缺口。
- 验收：e2e 覆盖一个跨两个工作区的任务从创建到在画布上显示。

### S3-07 Focus 悬浮窗 · todo
- 依赖：无
- 内容：独立窗口（无边框、透明、置顶、不抢焦点、不进任务栏），默认贴右下角；标题行"需要你 n · 运行中 m"、收起/展开；列表只列待批准、待审阅的会话，点开看最新一段内容，待批准可就地批准；"在工作台打开"跳到对应会话；透明区域点击穿透。托盘或主窗口里可以开关 Focus。
- 验收：e2e（测试模式下窗口放屏幕外）：有待批准时出现条目并能就地批准；截图。

### S3-08 多显示器与 DPI · todo
- 依赖：S3-07
- 内容：Focus 位置按所在显示器的工作区计算，记住上次位置；显示器变化（拔插、改缩放）时重新贴边；主窗口记住位置和大小，越界时拉回主显示器。
- 验收：单元测试覆盖位置计算（多显示器、不同缩放、越界）；真机观感写入"请你过目"。

- 验收：ROADMAP 阶段 3 的验收通过。
