## 各项场景与做法

### S11-A 画布管理（需求 1、2）

- 在画布上新建的任务一定显示在画布上；在看板（新建任务页）建的任务，如果选了专题，可以勾选「显示在画布上」（默认不勾）。任务页可以随时切换。
- 画布工具栏加「引用任务」：弹出搜索框，列出所有任务（可按项目、专题筛选），选中后在画布上放一张引用卡片。卡片和普通任务卡长得不同（虚线框 + 所属专题名），双击打开任务，可以拖动、放进分组，删除卡片不影响任务。同一个任务可以有多张引用卡片（在不同专题里）。
- 从画布进入新建任务页：「返回」回到画布；创建后打开任务页，任务页的「返回」也回到来的地方（画布或看板）。
- Bug：画布为空时，最后一个空分组点删除后不消失（用户说现场还在）。

### S11-B 对话附件与引用（需求 3）

- 第一步：在输入框粘贴图片、从文件管理器拖入图片，显示缩略图，可以删除，发送时作为图片交给 Codex（`localImage`）或 Claude（图片内容块）。对话记录里显示图片，点开看大图。
- 拖入非图片文件：变成文件引用 chip（路径），发送时以「引用文件：路径」附在消息后。
- `@`：在现有的 @ 任务之外，加上本项目的会话、常用文件（最近改动的文件），按类别分组。
- 文件选择器（Ctrl+P 或 @ 菜单里的「找文件…」）：弹窗模糊搜索项目文件（`git ls-files`，无 git 时遍历目录，跳过 node_modules 等），显示路径、大小和修改时间，回车插入引用。像 Everything 那样全盘索引的需求较大，另开专项。

### S11-C 便签小窗（需求 4）

- 照旧 AMO 的 ScratchpadApp：独立置顶小窗，全局快捷键（沿用旧 AMO 的默认键，设置里可改）唤出和隐藏；多页，页数可调；内容存在 Host（Store 的 kv），所有窗口共享。
- 可以粘贴图片（存进 attachments），在便签里显示缩略图。
- 任务页右栏的草稿区改为显示当前页摘要，加「打开便签」入口。

### S11-D Git Review（需求 5）

- 任务页、会话、项目（左栏右键或项目页）都能打开 Review 窗口（独立窗口），只对有 git 的项目可用。
- 左侧是改动文件列表：工作区改动（暂存和未暂存）+ 当前分支相对于默认分支合并基点的提交，可以切换对比范围；显示每个文件增删的行数。
- 右侧是 diff：「只看改动」（各段 hunk）和「完整文件」（整份文件，改动行高亮）两种视图。
- 每一行都能加批注；批注保存；「发给会话」把「文件:行号 + 原行 + 批注」汇总成一条消息发给选定的会话（默认是打开 reviewer 的那个）。

### S11-E Token 速度与上下文（需求 6）

- 每轮页脚显示输出速度（输出 token ÷ 生成用时，单位 tok/s）；生成中显示实时估算。
- 会话的输入框下方显示上下文占用：当前上下文 token / 模型最大上下文（Codex 来自 `thread/tokenUsage/updated` 的 `modelContextWindow`，Claude 来自 SDK 结果里的 `contextWindow`），超过 80% 变色。

## 怎么并行

- 先在 `studio/main` 上做公共底座 **S11-0 附件存储**（Host 的 attachments 功能：上传、读取；界面的上传工具），提交后再分线开发，避免几条线各做一份。
- 每条线一个 git 工作树和分支（`studio/s11-canvas`、`studio/s11-attach`、`studio/s11-scratchpad`、`studio/s11-gitreview`），由各自的 agent 开发；S11-E 由主会话自己做。各线只跑与自己相关的单元测试和端到端测试，合并后由主会话跑全量测试。
- 共用文件的约定：
  - `protocol/src/api.ts`、`features/index.ts`、`ui/src/features.ts`、`main.tsx` 只追加，不调整已有行的顺序。
  - 数据库迁移只有 S11-D 可以加（编号 8）；其他线用 kv 或画布文档存数据。
  - 新窗口（便签、Review）各写一个独立文件（`app/src/scratchpad-window.ts`、`app/src/review-window.ts`），在 `main.ts` 里只加启动调用。
- 都用 mock 模型测试，不调真实模型。
